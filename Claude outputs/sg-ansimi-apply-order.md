## 2. ⚠⚠ id 를 **신호 이름으로** 붙인다 — 매핑이 없어진다

지금 `Signal → 표정` 지도가 **두 곳에 적혀 있고 잠그는 검사가 없다.**

    index.html:657     var FACE = { GREEN:"calm", AMBER:"alert", RED:"worried", UNKNOWN:"unsure" };
    landing.html:250   ({ GREEN:"calm", AMBER:"alert", RED:"worried", UNKNOWN:"unsure" }[sig] || "unsure")

id 를 바꾸는 지금이 이걸 없앨 자리다. **symbol id 를 신호 값 그대로 쓴다.**

    ansimi-GREEN · ansimi-AMBER · ansimi-RED · ansimi-UNKNOWN · ansimi-look

그러면 두 곳의 `FACE` 지도를 **지운다.** 코드는 이렇게만 남는다.

    "/static/mascot.svg#ansimi-" + sig        (sig 가 없으면 UNKNOWN)

⚠ 이게 §6 이다 — 같은 판단을 두 곳에 적지 않는 가장 싼 방법은 **적을 곳을
  없애는 것**이다. `owner.js` 로 옮기는 방법도 있지만 `landing.html` 이
  `owner.js` 를 안 싣는다(실측: index · watch 만 싣는다). 스크립트를 첫
  화면에 새로 얹는 것보다 이쪽이 낫다.

⚠ 디자이너 시안의 라벨도 **정상 · 주의 · 위험 · 모름 · 확인 중** 이다 —
  곧 신호 이름이다. 이름이 맞아떨어진다.

### 검사 (반대 방향까지)

    · 스프라이트의 id 집합 == `Signal` 값 넷 + `look` · 그 외 id 없음
    · `static/*.html` 에 `FACE` 지도나 `calm|alert|worried|unsure` 문자열이
      **0건** — 되돌리면 실패해야 한다
    · `mungchi|kkureomi|kongi` 가 `static/` 에 0건

### (2) §1-4 — **돋보기 금지를 좁힌다**

지금: "체크·X·엄지·**돋보기**·방패 같은 판정·감시 기호는 어디에도 없다."

바꿀 내용:

```
4. **캐릭터는 표정만 짓고 말은 하지 않는다.** id 가 곧 신호다
   (`ansimi-GREEN|AMBER|RED|UNKNOWN`, 로딩은 `ansimi-look`) — 지도를 따로
   적지 않는다(§6). 말풍선에 결론 문구를 넣지 않는다. 몸에 신호등 색을
   쓰지 않는다. 체크·X·엄지·방패 같은 **판정·보증 기호는 어디에도 없다.**

   ⚠⚠ **돋보기는 금지가 아니다** (2026-09-18 정정). 금지의 목적은 "문장이
     못 하는 주장을 그림이 하는 것" 을 막는 것이고, 우리가 못 하는 주장은
     안전하다·합법이다·판매 가능하다·막아 준다 넷이다. 방패는 "막아 준다",
     배지는 권한, 체크는 "괜찮다" 라서 금지다. **돋보기는 "들여다본다" 이고
     그것은 우리가 할 수 있는 유일한 주장이다.** 제품 이름이 안심 소싱
     돋보기다.

     다만 선이 있다 — 돋보기가 **몸**인 것과 상품에 **겨누는** 것은 다르다:
       ✓ 머리가 렌즈다
       ✗ 상품·서류를 향해 돋보기를 겨누는 포즈
       ✗ 렌즈 안의 체크표시 · "찾았다" 반짝임
       ✗ 검사관·탐정 소품 (모자·수첩·파이프)
```

## 5. 남는 한계 — 미완 §1-m 에 적는다

    · **래스터다.** 88px 2배 화면에 176px 이 필요하고 원본이 162~175px 이라
      딱 맞거나 1~8% 모자란다. 지금 쓰는 자리까지는 문제없다

      SVG 가 오면 작은 크기 전용으로 눈·입을 굵게 다시 그릴 수 있다
    · 시안에서 **flood fill(허용치 60)** 로 떼어낸 것이다. 다크 바탕에서
      후광이 없는 것은 확인했다(총괄 실측)
    · `ansimi-head-*` 네 개(GREEN 외)는 지금 안 쓴다. `design/` 에 재료로 둔다
    · **SVG 원본이 오면**: 같은 id 로 `mascot.svg` 만 교체. 코드·검사 변경 0
