## 1. 어떻게 떼어냈나

시안이 평면 이미지라 배경을 지워야 했는데, **바디(`#FFF6E9`)와 패널 바탕이
채널 합 9 차이**라서 색으로 지우면 몸통이 같이 지워집니다.

그래서 **테두리에서 안쪽으로 흘리는 방식**(flood fill)을 썼습니다 — 렌즈 링과
몸통 외곽선이 닫힌 선이라 거기서 멈춥니다. 허용치 60에서 몸통·다리·손잡이·
얼굴이 전부 남고 배경만 사라졌습니다.

그다음 48색으로 줄이고 실제 필요한 크기(전신 176px · 머리 64px)로 맞췄습니다.
**계단이나 띠 현상 없습니다** — 첨부 `sg-ansimi-raster-check.png` 에서 88px
확대본까지 확인했습니다.

## 2. 실측 — 첨부 두 장으로 확인

### `sg-ansimi-raster-check.png` (최적화본 실제 적용 크기)

    로딩 88px (흰색)          다섯 표정 모두 또렷 · 띠 현상 없음
    결과 카드 44px (흰색)      또렷 · 표정 구분됨
    헤더 32px (크림)          또렷
    헤더 32px (다크)          또렷 · **후광(halo) 없음** ← 떼어낸 자리가 깨끗하다
    파비콘 20px · 머리만       눈·입 보임 · 다섯 표정 구분됨

### `sg-ansimi-apply-test.png` (20px 전신 vs 머리만)

같은 20px인데 **전신은 얼룩이고 머리만은 얼굴이 보입니다.** 이게 핵심입니다 —
전신 20px은 전체 높이의 절반을 몸통이 먹어서 눈이 1px이 되고, 머리만 쓰면
렌즈가 20px을 다 써서 눈이 4px 확보됩니다.

**디자이너에게 20px 전용본을 다시 받지 않아도 됩니다.** 우리가 자른 것으로
충분하고, 나중에 SVG 가 오면 그때 교체하면 됩니다.

## 3. 넣는 방법 — 구조를 안 바꿉니다

지금 화면은 이렇게 부릅니다.

    <svg><use href="/static/mascot.svg#mungchi-calm"/></svg>

`mascot.svg` 안의 `<symbol>` 에 PNG 를 base64 `<image>` 로 넣으면 **부르는
쪽은 그대로**입니다. 외부 파일을 더 받지 않으므로 요청 수도 안 늘어납니다.

    sourcing_guard/static/mascot.svg     symbol 5개 · 안에 base64 PNG
    sourcing_guard/static/favicon.svg    머리만 버전
    id                                   mungchi-* → **ansimi-***

⚠ **id 는 바꿔야 합니다.** 캐릭터가 안심이인데 id 가 `mungchi-` 로 남아 있으면
  §6 의 "정확한 이름" 을 어깁니다. 참조가 `static/*.html` 에 **11곳**,
  검사에 2곳입니다 — 기계적인 치환이고, **id 목록을 잠그는 검사 하나**를
  같이 넣으면 다음에 하나만 남는 사고가 안 납니다.

⚠ `design/README.md` **3행**(마스코트 A 뭉치)과 **§1-4**(돋보기 금지)도
  같이 고칩니다. `[디자인]` 표지를 단 커밋 하나로 묶습니다 — README 5행이
  요구하는 절차입니다.
