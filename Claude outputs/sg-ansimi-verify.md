## 2. 파비콘 — 네 불확실 #1 을 닫는다

헤드리스가 파비콘을 안 받아 간다는 네 관찰이 맞다. 그래서 **탭 표시가 아니라
파일 자체**를 쟀다 — 그쪽이 틀릴 수 있는 자리다.

    HTTP 200 · image/svg+xml · 2,145B
    20px · 32px · 64px 로 직접 렌더 → **20px 에서 눈 둘과 입이 또렷하다**

**머리만 쓰기로 한 판단이 맞았다.** 전신 20px 은 눈이 1px 이었는데 지금은
4px 이다. 캡처를 붙였다 (`sg-ansimi-favicon-check.png`).

남은 것은 "크롬 탭이 이 SVG 를 받아 가는가" 하나이고, 그건 200 · 올바른
`content_type` 이면 거의 확정이다. 육안 확인은 시피님 몫으로 넘겨도 된다.

## 3. 새로 나온 것 — **파비콘 viewBox 가 정사각이 아니다**

    viewBox="0 0 64 49"   비율 1.31

탭 슬롯은 정사각이다. 20×20 자리에 넣으면 **20 × 15.3px 로 들어가고 세로
4.7px 이 빈다.** 정사각으로 바꾸면 아이콘 면적이 **약 31% 커진다.**

    고치는 법   viewBox 를 `0 0 64 64` 로 하고 머리를 세로 가운데에 놓는다
                (그림은 안 바꾼다 — 캔버스만 정사각으로)

⚠ **오늘 하지 마라.** 네 번째 배포를 이미 했고, 이건 31% 를 얻는 일이지
  안 보이던 것이 보이게 되는 일이 아니다. **§1-m 에 한 줄 적어라.**
  SVG 원본이 올 때 같이 한다.

## 4. ⚠ 내 정정 — "인증 조회가 살아 있다" 는 내가 확인한 것이 아니다

배포본에 실호출을 두 번 넣고 `cert: 조회함` 을 보고 "살아 있다" 고 읽을
뻔했다. **틀렸다.** 재 보니 이렇다.

    실호출 1 · 2   결과 GREEN/RED · cert 조회함
    extraction.llm  14 → 15   (LLM 은 진짜 돌았다)
    results.scans   14 → 15
    kats.calls      9 → **9**  ← 정부 API 를 **안 불렀다**

이유를 찾았다 — `verifier.py:1239` 가 `kats.lookup_certification_cached(num)`
다. 내가 쓴 두 인증번호는 **네가 아까 확인할 때 이미 캐시에 들어간 것**이라
바로 나왔다.

⚠ 그리고 이건 **잘 만들어진 설계다.** `verifier.py:1289` 가 `lookup.stale` 을
  보고 "조회 서비스에 연결하지 못해 YYYY-MM-DD 조회분으로 …" 라고 말한다.
  못 부르면 캐시를 쓰되 **언제 조회한 것인지 화면에 적는다.** §9 그대로다.

⚠ 그래서 **오늘 살아 있는 KATS 증거는 네 9회가 전부다.** 내 두 번은 아니다.
  내가 "확인했다" 고 적을 뻔한 것을 적어 둔다 — 오늘 네 번째로 걸린
  "잰 범위와 결론의 범위" 자리다.

## 5. Phase 3 감시 목록 보강 — `kats.failure_rate` 를 더한다

네 불확실 #2(9회 중 3회 `network`)가 이걸 드러냈다.

    consecutive_failures   0    ← 연속 실패는 없다
    failure_rate           0.333 ← **셋 중 하나가 실패했다**
    last_error_at  07:20:04 → last_success_at 07:20:43  (40초 만에 회복)

**간헐 실패는 `consecutive_failures` 에 안 잡힌다.** 33%가 계속되면 캐시에
없는 인증번호를 넣은 셀러 **셋 중 하나가 "조회 실패"** 를 본다. 그런데 연속
실패는 0 이라 우리 감시가 초록으로 보인다.

Phase 3 목록에 한 줄 더한다:

```
kats.failure_rate    0.2 를 넘으면 기록한다. consecutive_failures 가 0 이어도
                     간헐 실패는 여기에만 보인다 — 2026-09-18 배포 직후 0.333
                     이었다(9회 중 3회, 40초 만에 회복). 9/15~18 장애의 꼬리인지
                     새 것인지는 모른다.
⚠ 그래도 **투표 중에는 배포하지 않는다.** 기록하고 본선으로 넘긴다.
```
