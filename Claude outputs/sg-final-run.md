## 2. 히어로를 여덟 화면 전부에 + 시안 마스코트 교체

### (1) 히어로가 없는 여섯

지금 `/` 와 `/scan` 만 히어로로 시작한다. 나머지 여섯이 `<h1>` 로 바로 시작해서
**같은 서비스로 안 보인다.** `/scan` 히어로 껍데기를 그대로 쓴다.

```
띠(그라데이션) · 칩 · 제목(두 줄) · 부제 · 마스코트
```

**제목·부제는 지금 각 화면의 h1/lead 를 그대로 옮긴다. 새로 쓰지 마라.**

칩 여섯 (새 문장 · §9 검사 대상):

```
/batch     대량 검사
/watch     감시 목록
/samples   체험 표본
/misses    우리가 틀린 것
/guide     카테고리 가이드
/unknown   모름 안내
```

칩은 "여기가 어디인가", 제목은 "여기서 뭘 하나" 다. 겹치지 않는다.

### (2) 마스코트 그림 — `Claude outputs/hero/` 에 있다

총괄이 시안 이미지에서 떼어낸 PNG 다. **말풍선은 잘라 냈고 소품은 그대로다.**

```
hero-look.png    돋보기 + 몸        →  랜딩 · /scan
scan-full.png    클립보드 + 방패 + 문서 →  /scan 대안 (시피님 판단: 초록 그대로)
bulk-full.png    클립보드 + 엑셀 + 문서 →  /batch
나머지 다섯 화면    지금 `ansimi-look` 스프라이트 그대로 — **더 선명하다**

(scan-brand.png · bulk-brand.png 는 색상만 브랜드 보라로 돌린 판이다.
 시피님이 초록으로 가라고 하셨으므로 **full 을 쓴다.** 나중에 바꾸려면 파일만 교체)
```

⚠⚠ **히어로 그림은 신호 스프라이트가 아니다.** `mascot.svg` 의 다섯 id
  (`ansimi-GREEN|AMBER|RED|UNKNOWN|look`)와 **섞지 말고 별도 자산으로** 둬라.
  섞으면 `/misses` 히어로에 `ansimi-GREEN` 이 떠서 "우리가 틀린 것" 페이지에
  초록 얼굴이 뜬다. **id 가 곧 신호라서 생기는 사고다.**

⚠ **결과 카드 안 마스코트는 안 건드린다.** 거기는 판정 자리고 신호를 따라간다.
⚠ **결과 화면에는 히어로를 안 넣는다.** 시안 화면3도 없다. 결과가 나오면
  히어로가 위로 밀려나면 된다.
⚠ PNG 위 모서리에 말풍선 글자 조각이 몇 픽셀 남아 있을 수 있다. **떠서 보고
  남으면 잘라라.**
⚠ `<img>` 로 바꾸지 말고 지금 구조를 유지해라 — 원본이 오면 파일만 갈아 끼우게.

⚠ 미완 §1: **히어로 그림이 1.0~1.16x 다.** 2배 화면에서 흐리다. 디자이너에게
  원본(512px 또는 SVG)을 받으면 교체, 코드 변경 0.

## 3. `/batch` 끌어다 놓기 — **붙여넣기 위에 얹는 편의**

시피님이 엑셀 업로드를 물었고, 재 보니 **오늘 하면 안 되는 이유가 시간이 아니라
정확성**이다. 열이 여럿인 파일에서 우리가 열을 고르면 **틀린 열을 조용히 검사한다.**

```
.csv / .txt 를 떨어뜨림
  열 하나      → FileReader 로 읽어 **기존 붙여넣기 칸에 채운다**
                 (그다음은 지금 경로 그대로 · 서버 변경 0 · 검사 변경 최소)
  열 둘 이상    → **채우지 않는다.** 이렇게 알린다:
                 "열이 N개입니다. 어느 열이 상품명인지 저희가 고르면 틀릴 수
                  있어서 넣지 않았습니다 — 그 열만 복사해 붙여넣어 주세요."

.xlsx 를 떨어뜨림
               → 파싱하지 않는다. 안내만:
                 "엑셀 파일은 열을 복사해 붙여넣어 주세요. 저희가 어느 열인지
                  고르면 틀릴 수 있습니다."
```

```
✗ 외부 스크립트 금지 — 저장소에 외부 JS 가 **0건**이다. 그 상태를 깨지 마라
✗ 서버 업로드 엔드포인트 금지 — .xlsx 는 zip 이다. 공개 서비스에 zip 폭탄·
  XML 엔티티 면을 여는 일이다
✗ openpyxl 같은 새 의존성 금지
```

검사: 열 하나 csv → 칸이 채워진다 · **열 둘 csv → 안 채워지고 안내가 뜬다**
(반대 방향) · xlsx → 안내만 · §9 금지어 · 500줄 상한 그대로.

⚠ 미완 §1: **.xlsx 는 열 선택 UI 가 먼저다.** 첫 줄을 보여 주고 셀러가 고르게
  하는 것이 순서이고, 그다음에 파서를 넣을 값이 생긴다. **순서를 뒤집으면
  틀린 열을 검사한다.**

## 5. 물놀이 — **재기만 해라**

`scripts/replay_single_path.py` 는 LLM 0회다. 별칭·가드 수정은 그 부류다.

```
1. 고침 없이 재생 → 지금 값 확인 (104 · 0 · 104 · 0 · 3)
2. 「물놀이」를 핵심명사에 걸릴 때만 쓰게 고치고 재생
3. **다섯 숫자와 바뀐 행 수만 보고 보고.** 고치는 것은 그다음이다
```

⚠ 시피님 제출 여부에 걸려 있다. 숫자가 움직이면 제출 서류와 사이트가 다른
  말을 하게 되므로 **내 판단을 받고 나서** 커밋해라.
⚠ 새 기계를 만들지 마라 — `_ITEM_EXCLUSION_MARKERS` 와 부속품명 장치가 이미 있다.
