## 1. F2 파비콘 — 그대로 둔다. 내 계산을 정정한다

    본선    디자이너 SVG 원본을 받을 때 **정사각 구성의 머리**를 함께 요청한다

## 2. G2-B 표본 비용 — 기록본으로 간다

### 판정

**표본 8~10개는 실측한 결과를 파일로 담아 그린다.** 랜딩 미리보기가 이미 그 방식이다
(`demos.py` · `demo_amber_result.json`). 같은 기계를 늘리는 것이지 새 기계가 아니다.

    기본      기록본을 그린다 — LLM 0회 · KATS 0회 · **즉시**
    버튼      "지금 다시 검사" → 일반 `/api/v1/scan` · **일반 예산 안에서** (면제 아님)
    면제 지문  기존 데모 셋 그대로. **늘리지 않는다**

### 왜 이쪽인가

    · 투표자의 첫 10초에 LLM 6초 대기가 없다. 버튼을 누르면 카드가 바로 뜬다
    · 18일 × 공개 투표 × 10개 버튼 = 면제로 두면 뚜껑 없는 비용이다
    · KATS 가 죽어 있어도(지금 그렇다) 기록본은 **그날 실제로 나온 결과**다
    · "다시 검사" 가 있으니 "기록만 보여 준다" 는 의심에 답이 있다

### 정직하게 — 라벨 두 줄이 필수다

기록본 카드 위에 이 두 줄을 **반드시** 둔다. 없으면 이건 체리피킹이고 심사위원은 안다.

    "이 결과는 저희가 2026-09-19 에 실제로 검사한 것입니다. 지금 다시 검사하실 수 있습니다."
    "여기 있는 것은 저희가 맞힌 예입니다. 실상품 135건 기준 품목 적중 104건(77.0%)이고,
     틀린 8건과 못 맞힌 19건도 저장소에 공개돼 있습니다."

⚠ 날짜는 각 기록본의 실제 `fetched_at` 에서 온다. 손으로 적지 않는다.
⚠ "다시 검사" 를 눌렀는데 KATS 가 죽어 있으면 시드 캐시가 `stale` 로 답한다 —
  "조회분으로 표시합니다" 가 뜬다. **그게 맞는 화면이다.** 막지 않는다.

## 3. 표본 구성 — **기간만료 5 · 안전인증취소 2 를 뺴지 않는다**

네가 잰 것: 도매꾹 실상품 27개 번호 · **적합 22 · 기간만료 5 · 안전인증취소 2.**

**이 7건이 이 제품이 존재하는 이유다.** 인증번호가 버젓이 적힌 실제 도매 상품인데
인증이 만료됐거나 취소됐다 — 인증번호만 보는 셀러는 이걸 놓친다. 적합 22개만 늘어놓은
표본은 "잘 되네" 로 끝나고, **만료·취소가 섞인 표본은 "이게 필요하구나" 로 끝난다.**

    표본 10개  적합 5 · 기간만료 3 · 안전인증취소 2  ← 이 비율을 권한다
              품목은 흩는다 (튜브 · 주전자 · 그릴 · 매트 · 색연필 · 충전기 · 방석 · 청소기)
    순서      취소 하나를 **맨 앞**에 두지 않는다. 적합 → 만료 → 취소 순으로 읽히게.
              첫 카드가 빨강이면 "겁주는 서비스" 로 읽힌다

### ⚠ 이 수를 발표에 쓸 때 — 분모를 정직하게

    ✗ "도매꾹 상품 26% 가 인증 만료·취소"
    ✓ "인증번호가 적힌 도매꾹 실상품 27건 중 7건이 기간만료 또는 취소 상태였습니다
       (2026-09-19 국표원 조회 기준)"

27은 **인증번호가 적힌 것만 고른** 수라 시장 전체 비율이 아니다. 그걸 빼면 과장이다.
그래도 이 문장은 충분히 세다.

### ⚠ 상호·공급사명은 한 글자도 안 나간다

표본 카드의 상품명에서 `[상호]` 꼴 접두와 공급사 식별 정보를 뗀다.
`domeggook_pii` 의 규칙 그대로. 검사로 잠근다 — 표본 문구에 `[` 로 시작하는 토큰 0건.

## 4. `stale` 넷째 값 — 승인. 확인 하나

네가 찾은 것이 맞다. 시드를 얹으면 화면 바닥이 "정부 조회 인증 성공" 인데 바로 위
근거 줄이 "연결하지 못해 조회분으로 표시" — **한 화면에서 두 줄이 반대를 말했다.**
메모리 캐시일 때도 같았지만 검사가 빈 캐시로 돌아 안 보였다는 진단도 맞다.

    ok / stale / failed / not_attempted   소유자 하나 (`GOV_LOOKUP_STATES`) · 화면 대응표를 검사가 대조

기존 검사 16건을 약화시키지 않고 **두 세계로 가른** 것 — 그게 §6 이다. 시드 없는
세계에서 `failed` 는 여전히 참이고, 시드 있는 세계에서 `stale` 도 참이다.

### 확인 하나

`gov_lookup_state` 는 바닥 표시용이라고 했다. **신호로 새지 않는지** 한 줄로 확인해라 —
데모 셋의 `signal` 이 시드 전/후 동일한가. 다섯 숫자는 품목 경로라 이걸 안 잡는다.

## 5. KATS — 한국에서는 되고 도쿄에서는 안 된다

네가 시드 29건을 **한국 기계에서 29/29 성공**으로 받았다. 같은 시각 도쿄 배포본은
`consecutive_failures 3 · failure_rate 0.5 · last_success 9/18 07:20Z` 다.

    한국(네 기계)   29 / 29 성공
    도쿄(fly nrt)    6 / 12 실패 · 어제부터 성공 0

**지역 가설이 서는 자리다.** 정부 서버가 국외 발신을 느리게 받거나 끊는 것일 수 있다.
9/15~18 장애도, 오늘 재발도 같은 그림이다.

### 측정만 한다 — 오늘 밤은 이동하지 않는다

    할 것    fly 에 **icn(서울) 임시 머신** 하나를 볼륨 없이 띄우고, 어제 쓴 탐침을
            그 안에서 돌린다 — `www.safetykorea.kr` 이름 풀이 + `/openapi/api/...` 한 번
            성공하면 지역 가설 확정. 임시 머신은 바로 지운다
    안 할 것  **프로덕션 이동.** 볼륨(워치리스트 · 리콜 사본 37,430건)이 nrt 에 묶여 있어
            옮기는 게 위험이다. 투표 전날 밤 일이 아니다 — **본선 첫 과제**로 올린다
    기록     결과를 §1-m 에 적는다. 확정되면 "본선: primary_region icn 이전 + 볼륨 복제"

⚠ 10분짜리 측정이다. G1~G3 을 막지 않는다. 시간이 나면 하고, 안 나면 미완에
  "가설 · 미측정" 으로 적는다.
