## P1. 타임아웃을 설정으로 빼고 30초로 재본다 — **먼저 합니다**

### 왜 먼저인가

인증 조회도, 리콜 동기화도, 플랫폼을 옮길지 말지도 **전부 이 답에 달려
있습니다.** 16.88초는 "거절당했다" 가 아니라 **"8초 안에 답이 안 왔다"** 입니다.
한국에서 0.39초인 서버가 도쿄에서 8초를 넘긴다면, 30초를 주면 될 수도
있습니다. **안 재보고 플랫폼을 옮기는 것은 비쌉니다.**

### 할 일 (코드 3줄)

    config.py     kats_timeout: float = 8.0        ← 환경변수로 읽게
    main.py:118   KatsClient(..., timeout=settings.kats_timeout)
    kats_client   기본값은 그대로 8.0 (호출부가 안 넘기면 지금과 같다)

배포 후 fly secret 으로 재봅니다:

    KATS_TIMEOUT=30  →  POST /api/v1/sync 를 친다
                     →  성공하면 답이 나온 것이고, 리콜 사본도 같이 채워진다
                     →  실패하면 8초든 30초든 안 오는 것이다

⚠ **결과를 숫자로 적으십시오.** 성공/실패만이 아니라 **몇 초에 답이 왔는지**.
  그 값이 운영 타임아웃을 정합니다 (30초를 그대로 두면 셀러가 30초를
  기다립니다 — 화면이 멈춘 것처럼 보입니다).

⚠ 재고 나면 **적정값으로 내립니다.** 측정용 30 을 운영에 두지 않습니다.
  ⚠ 그리고 `verifier` 가 이 타임아웃을 기다리는 동안 셀러 화면이 비어
    있습니다. 15초를 넘길 거면 화면에 "정부 조회 중" 표시가 필요합니다 —
    §1-p 와 별개로 재 보고 판단하십시오.

### 세 갈래 결과

    ① 30초로 성공한다   → 운영값을 올린다. **플랫폼 이전 불필요.** 리콜도 채워진다
    ② 30초도 실패한다   → 시간 문제가 아니다. P6(국외 지점 시험)으로 간다
    ③ 가끔 성공한다     → 불안정이다. 재시도를 넣을지 판단한다
                        ⚠ `kats_client.py:133` 주석이 "재시도를 넣지 않는다 —
                          남의 API 장애로 우리를 죽이지 않는다" 고 적어 뒀습니다.
                          **그 판단을 뒤집으려면 이유를 그 주석 옆에 적으십시오**

## P2. 문구 — 원인을 말하지 않는다

`sg-lookup-honesty.md §3` 그대로입니다. 요약:

    지금      "일시적으로 …  잠시 후 다시 시도해 주세요"   ← 일시적이라고 단정
    금지      "지금 이 서버 위치에서 …"                    ← 지역이라고 단정
    고칠 것    사실 + 관측 + 항상 참인 다음 행동. **원인은 안 적는다**

문안 초안:

    "국가기술표준원 조회 서비스에 연결하지 못했습니다. 인증 확인이 완료되지
     않았습니다. 아래 근거 링크에서 번호를 직접 조회하실 수 있습니다."

연속 실패가 임계 이상일 때만 한 줄 더 (원인이 아니라 우리가 센 값):

    "최근 조회 시도가 계속 실패하고 있습니다."

    두 곳을 같이 고친다   verifier.py `_lookup_failed()` · scorer.py UNKNOWN 헤드라인
    양쪽 조건을 본다      이번 코드가 network **이고** consecutive_failures ≥ 임계

## P4. 도매꾹 상품 리스트

### ⚠ 약관이 확정됐습니다 — hotlink 금지

> "이미지 사용이 허용된 경우에는 제공된 이미지를 **다운로드 받아 사용하고
> 있는 이미지호스팅 서비스에 저장하여 사용**하시기 바랍니다."

    ✗ <img src="도매꾹 CDN URL">        약관 위반
    ✓ 우리가 받아서 /static/ 에 저장    약관이 지시한 방식

그리고 조건절이 있습니다 — **"이미지 사용이 허용된 경우에는"**. 응답에
`desc.license.usable` / `msg`("상세 이미지 타 마켓 사용 허용 여부")가 있습니다.

⚠ **그 필드가 썸네일(`list.item.thumb`)까지 덮는지는 확인 안 됐습니다.**
  상세설명 이미지에 대한 것일 수 있습니다. **`usable` 이 true 인 상품만
  쓰고, 애매하면 이미지 없이 갑니다** — 리스트는 이미지가 없어도 성립합니다
  (제목·가격·최소수량·카테고리).

### 순서

    a. getItemList(ca=…, so="rd", sz=100)   1회   → 상품 100개
    b. getItemView(multiple=true, no=…)      1회   → 상세 100개
    c. license.usable 확인 → 허용된 것의 이미지만 내려받아 /static/ 에 저장
    d. safetyCert[].no 가 있는 상품만 추려 국표원 조회 (한국에서) → seed 에 추가
    e. 사본을 만든다 — **남길 목록** 정제로
    f. 화면: 리스트 → 클릭 → 결과

### 남길 목록 — 다섯 필드만

    no · title · thumb(로컬 경로) · url · price
    그 밖 전부 버린다 — 특히 id · nick · seller.* · return.*

⚠ `domeggook_pii.write_sanitized()` 는 **지울 목록**이라 새 필드가 남습니다.
  이 경로에는 `mfds_pii.py` 를 본보기로 **새 남길-목록 함수**를 만드십시오.
  CLAUDE.md §6: *"쓰는 필드를 셀 수 있으면 남길 목록 쪽이 강하다."*

### 화면 규칙 — 총괄 판정

    리스트 카드    제목 · 썸네일 · 가격 · 최소수량. **신호를 칠하지 않는다**
    클릭 후        거기서 처음 신호를 보여준다
    RED 상품       리스트에 넣지 않는다. 빨강 사례는 지금처럼 /samples 익명 기록본
    결과 화면 한 줄  "이 결과는 상세페이지에 적힌 인증번호를 정부 DB 에 조회한
                  것이며, 상품이나 판매자에 대한 평가가 아닙니다."
    기준일 표기     "2026-09-20 기준 도매꾹 판매중 상품" · 도매꾹 원문 링크 제공

⚠ 이유: 특정 판매자의 **실재하는 상품**에 우리가 빨간불을 붙여 공개하는
  것이기 때문입니다. 지금 `/samples` 는 `cert_number·title·text·result` 만
  담고 상품번호도 URL 도 판매자도 없습니다 — 익명입니다. 이 안은 한 걸음
  더 나가므로 그만큼 조심합니다.

⚠ 참조.md: *"판매중지·판매종료·품절·단종은 결과에 포함되지 않는다."* 목록에
  나온 순간에는 판매중이지만 **사본은 낡습니다.** 기준일을 적는 이유입니다.
