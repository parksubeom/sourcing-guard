# [총괄 지시] `/guide` 를 다시 만든다 — **표를 내리고 답 하나를 남긴다**

시피님 판정이다. 지금 페이지는 **셀러에게 값이 거의 없고 우리 약점만 크게
보인다.** 198행 표에 14% · 11% 가 줄줄이 있고, 「매칭률이지 정답률이 아니다」는
단서를 방문자는 안 읽는다.

---

## 0. 왜 바꾸나 — 두 가지

### (1) 셀러는 이 표를 쓸 이유가 없다

"내 카테고리가 되나?" 를 알고 싶으면 **그냥 붙여넣으면 10초**다. 확인보다
시도가 싼 서비스에서 사전 점검표는 안 쓴다. 이 표는 사실 **심사·납품·개발용**
이고, 사용자 화면 옷을 입고 있다.

### (2) ⚠⚠ 그리고 표의 숫자는 **셀러에게 적용되는 숫자가 아니다**

```
이 표        배치 경로 — 상품명 **글자만**, AI 안 씀
셀러의 검사   단건 경로 — 상세페이지 전체, AI 추출
```

**둘은 다른 경로다.** 「남성신발 14%」를 보고 "나는 14% 확률이구나" 로 읽으면
틀린다. 낮은 숫자를 보여 주면서 **그 숫자가 자기에게 해당하지도 않는다** —
보여 줘서 얻는 것이 없다.

⚠ 이건 감추자는 말이 아니다. `docs/M5_카테고리_가이드` 와
  `data/category_guide.tsv` 에 그대로 있고, 물으면 낸다. **화면에서 내린다.**

---

## 1. 새 화면 — 검색 하나, 답 하나

```
제목      내 카테고리가 되나요?
한 줄     도매 카테고리 198개 · 상품명 18,938개를 실제로 넣어 봤습니다.
          ⚠ 숫자는 **양**이지 정확도가 아니다. 이 한 줄만 남긴다

[ 카테고리 검색 ________________ ]

(입력 전)  자주 찾는 것: 유아동잡화 · 남성가방 · 생활용품 · 디지털/가전 · 출산
```

### 답은 셋뿐이다. **새 분류표를 만들지 마라 — 지금 데이터로 갈린다**

```
① matched > 0
   「유아동잡화」 — 다룹니다
   이 카테고리 상품명에서 저희가 찾은 품목은 주로 「의류 이외의 섬유제품」이었습니다.
   [ 내 상품 검사하기 → ]

② matched == 0
   「선케어」 — 이 표본에서는 품목을 찾지 못했습니다
   저희가 다루는 것은 전기용품 · 생활용품 · 어린이제품입니다.
   ⚠ 다만 이 표본은 **상품명 글자만** 본 것입니다. 상세페이지에는 재질·대상연령
     처럼 상품명에 없는 정보가 있어서, 직접 넣으면 결과가 다를 수 있습니다.
   [ 그래도 넣어 보기 → ]

③ ①·②에 덧붙임 — jurisdictions 의 건수가 **10건 이상**일 때만
   ⚠ 이 카테고리 상품명에서 「화장품법(식품의약품안전처)」 표기가 28건
     관찰됐습니다. 해당 기준도 함께 확인하셔야 할 수 있습니다.
```

⚠⚠ **③을 "우리가 안 다룹니다" 로 쓰지 마라.** 덧붙이는 정보다.
  실측에서 **카시트는 자동차관리법 20건인데 어린이제품이기도 하다.** 소관
  관찰만 보고 밀어내면 진짜 대상 상품을 내보낸다.

⚠ **10건 문턱의 근거**: 실측에서 1~3건짜리가 잡음이다(남성가방에 화장품법 1건,
  침실가구 1건 — 상품명에 화장품 낱말이 섞인 것). 신호는 13~28건이다
  (선케어 28 · 남성화장품 22 · 카시트 20 · 스킨케어 19). **문턱과 근거를
  코드 주석에 적어라.**

⚠ **퍼센트를 화면에 쓰지 마라.** `matched_pct` 는 응답에 있어도 그리지 않는다.
  검사로 단정해라 — 화면에 `%` 가 0건.

### 맨 아래 한 블록

```
저희가 다루는 범위
  전기용품 · 생활용품 · 어린이제품 (전기생활용품안전법 · 어린이제품법)
  식품 · 화장품은 식약처, 의약외품은 별도 기준입니다.
  여행 · 음반처럼 물품이 아닌 것은 애초에 범위 밖입니다.
```

```

                            「매칭」을 설명하려고 일곱 단락을 쓰는 페이지는 안 읽힌다
✗ 숫자 타일 넷 (198·151·47·18938)  → 제목 아래 한 줄로 합친다
✗ 「매칭된 수」·「매칭률」 표기 전부   → 화면에서 % 0건
✗ 「매칭」이라는 낱말 자체         ← 쓸 자리가 없어진다. "저희가 찾은 품목" 으로 말한다
```

⚠ `category_guide.py` · `/api/v1/guide` · TSV 는 **그대로 둔다.** 검색이
  그 데이터를 쓴다. 지우는 것은 화면뿐이다.

## 3. 내비

```
지금   소개 · 상품 검사 · 대량 검사 · 감시 목록 · 카테고리 가이드
바꿈   소개 · 상품 검사 · 대량 검사 · 감시 목록 · 다루는 범위
```

「카테고리 가이드」는 무엇을 답하는 페이지인지 안 말한다. 「다루는 범위」가
짧고(8자→6자 · 320px 내비에 유리) 무엇을 답하는지 말한다.

⚠ 항목 수는 다섯 그대로다. **여섯째를 넣지 마라** — 320px 넘침이 §1-l 이다.

## 6. 순서

**이것보다 `/healthz` 의 `kats.failure_rate 1.0` 이 먼저다** — 인증 조회가
프로덕션에서 100% 실패하고 시드가 가리고 있다(로드맵 §0). 다만 그건 프록시를
띄워 봐야 알고 **오늘 붙잡고 있을 일이 아니면** 이 화면부터 해도 된다.

막히면 **내비 라벨만 바꾸고 멈춰라** — 「카테고리 가이드」를 「다루는 범위」로.
그것만으로도 첫 줄에서 약한 표를 가리키는 일이 줄어든다.
