## 0. 넘기기 전에 — 제가 두 가지를 정정합니다

### ① 앞서 보낸 3안 미리보기는 **다른 마스코트**로 그렸습니다

제가 `design/mascot-ansimi/mascot.svg` 의 `#ansimi-look` 심볼을 뽑아
썼는데, **`/scan` 에 실제로 뜨는 그림은 그것이 아닙니다.**

이미지의 마스코트는 **돋보기를 든 쪽**입니다 — 원하신 것이 그쪽입니다.

**다시 찍었습니다.** `히어로_C안_실제자산.png` 는 실제 `look.png` 로 그린
것이고, 이것이 반영 후 실제로 나오는 모습입니다.

## 1. 크기 — **새 값을 만들지 말고 랜딩 값을 가져옵니다**

랜딩이 이미 쓰는 값입니다. 옮겨 적는 것이 아니라 **같은 눈금을 쓰는
것**입니다.

    app.css:672  .hero-say h1{ font-size:60px; line-height:72px;
                               letter-spacing:-.015em }        ← 랜딩 (기준)
    app.css:679  .hero-say .lead{ font-size:20px; line-height:32px }

고칠 곳:

    app.css:222  .intro h2{ font-size:32px; line-height:1.3;
                            letter-spacing:-.01em }
              →  font-size:60px; line-height:72px; letter-spacing:-.015em

    app.css:223  .intro p{ font-size:19px }
              →  font-size:20px; line-height:32px

    app.css:986  .intro-face.art{ width:132px; height:112px }
              →  width:225px; height:225px

    app.css:224  @media (max-width:640px){ .intro h2{font-size:24px}
                                           .intro p{font-size:17px} }
              →  폰 눈금도 함께 올린다. 안 올리면 폰에서만 옛 값이 남는다

⚠⚠ **마스코트 박스는 1:1 입니다.** `look.png` 가 112×113 이고 배경이
  `contain` 이라, 박스를 세로로 길게 잡으면 그림이 작게 들어가고 위아래에
  빈 자리만 생깁니다. **225×225 로 잡아야 실제로 225px 높이로 그려집니다.**

⚠⚠ **두 곳이 같은 판단을 적고 있습니다** — `.hero-say h1`(랜딩)과
  `.intro h2`(도구 화면 여덟). CLAUDE.md §6: *"같은 판단을 두 곳에 적지
  마라. 조건이 갈리면 한쪽만 고쳐도 나머지가 거짓말을 계속한다."*

  **공용 클래스나 토큰으로 묶고, 묶었다는 사실을 주석에 적으십시오.**
  묶기 어려우면 최소한 양쪽 주석에 "짝이 어디인지" 를 적습니다. 이번에
  안 묶으면 다음에 누가 랜딩만 고칩니다 — **이번 건 자체가 그 증상입니다.**
  버튼에는 `app.css:274` 가 그 주석을 달아 뒀고, 제목에는 없었습니다.

## 2. 폰트 — Pretendard 1.3.9 · 제목과 워드마크만

### 버전과 경로는 확인했습니다 (R5)

    현행 버전   1.3.9      (jsDelivr 패키지 API 조회)
    라이선스    SIL Open Font License — 글꼴 단독 판매만 금지,
               상업적 사용·수정·재배포·웹폰트 임베딩 허용
    출처        https://github.com/orioncactus/pretendard

### 받는 곳은 **CDN** 으로 갑니다 — 총괄 판단

자체 호스팅도 길이지만 한글 폰트라 서브셋 작업이 붙고, 그건 오늘 할 일이
아닙니다. README:70 이 이미 *"본선에서 자체 호스팅으로 바꿀 수 있게
`--font-*` 변수 뒤에 폴백을 두었다"* 고 적어 뒀으니 **나중에 바꾸는 길이
열려 있습니다.**

⚠ 전체 정적 CSS 말고 **dynamic subset** 이 있으면 그쪽을 쓰십시오 — 제목에만
  쓰므로 필요한 글자가 적습니다. 없으면 정적으로 가되 **받는 굵기를 700
  하나로 제한**합니다. 400·500·800 까지 받으면 안 쓰는 것을 받는 것입니다.

### ⚠⚠ CLAUDE.md R4 의 「브라우저가 받는 곳」에 **먼저** 적습니다

지금 둘입니다 (`fonts.googleapis.com` · `fonts.gstatic.com`). 셋이 됩니다.

R4 가 정해 둔 판단 기준이 이미 있고, 그대로 통과합니다:

> *"새 호스트를 브라우저 쪽에 더할 때 물을 것 — 투표 기간에 그 호스트가
> 죽으면 화면이 어떻게 보이나. 폰트는 대체 글꼴로 떨어지므로 견딜 만하고,
> 스크립트는 아니다."*

⚠ **`ALLOWED_HOSTS` 에는 넣지 않습니다.** 그건 서버가 `httpx` 로 나가는
  곳이고, 이건 브라우저가 받는 곳입니다. R4 가 그 구분을 길게 적어 뒀습니다.

### 적용 범위

    --font-display   "Gowun Dodum",…  →  "Pretendard","Gowun Dodum",…
                     제목·워드마크에서 weight 700 을 쓴다
    --font-body      그대로 (Noto Sans KR)

⚠ `--font-display` 를 쓰는 규칙들이 지금 `font-weight:400` 을 명시하고
  있습니다 (`app.css:568-570` · `app.css:169 .t-display` · `app.css:672`).
  **굵기를 바꾸는 곳을 전부 찾아 같이 옮기십시오.** 하나만 고치면 화면마다
  제목 굵기가 갈립니다.

⚠ 고운돋움을 `<link>` 에서 **빼지 마십시오.** 폴백으로 남깁니다 — CDN 이
  죽어도 제목이 본문 글꼴로 떨어지지 않습니다.

## 3. 검사를 규칙에 맞춥니다 — **이번 건의 뿌리입니다**

    tests/test_static_cache_and_font.py
      def test_the_body_font_is_the_token_and_the_gov_design_font_is_gone()
      """정부 디자인 시스템 폰트는 쓰지 않는다 — app.css 머리주석 원칙."""
      ...
      assert "Pretendard" not in code          ← 규칙보다 넓다

규칙·주석·검사 **이름**이 전부 「GOV」·「공공 디자인 시스템 폰트」라고
적는데 단정만 넓었습니다. 좁힙니다:

    Pretendard GOV 만 막는다 — 대소문자·공백 변형 포함
      "Pretendard GOV" · "pretendard-gov" · "PretendardGOV"

⚠ **왜 좁혔는지 한 줄을 검사 옆에 적으십시오.** 안 적으면 다음 사람이
  "넓은 게 안전하다" 며 되돌립니다.

⚠⚠ **반대 방향을 한 줄 재십시오** (§6 — 이 저장소에서 네 번 난 자리).
  좁힌 검사가 `font-family:"Pretendard GOV"` 를 **실제로 막는지** 한 번
  넣어 보고 확인합니다. 통과해 버리면 가드가 사라진 것입니다.

⚠ 그리고 `test_the_body_font_token_actually_leads_with_the_webfont_we_download`
  가 `--font-body` 의 첫 글꼴이 `"Noto Sans KR"` 인지 단정합니다. 본문은
  안 건드리므로 그대로 통과해야 합니다 — **통과하는지 확인하고 넘어가십시오.**

## 4. 마스코트 자산 — **지금 파일로도 갑니다. 원본이 오면 더 좋아집니다**

    /static/hero/look.png    112 × 113   (표시 225 → 레티나 2x 로 450px)

4배 확대라 부드러워집니다. **다만 실제로 그려서 재 봤고, 견딜 만합니다** —
이 그림체가 굵은 윤곽선 + 넓은 면이라 확대가 잘 버팁니다. `히어로_C안_
실제자산.png` 의 마스코트가 실제 결과입니다.

⚠ **지금도 이미 흐립니다.** 112px 원본을 132×112 로, 레티나에서 264px 로
  그리고 있습니다. 이번 변경이 흐림을 만드는 것이 아니라 **이미 있던 흐림이
  커지는 것**입니다.

### 원본이 있으면 교체합니다

`app.css:976` 주석이 길을 미리 설계해 뒀습니다 —
*"원본(512px·SVG)이 오면 **파일만** 갈아 끼운다 - 마크업도 CSS 도 안 바뀐다."*

**시피님께 확인해 주십시오 — 외주에서 받은 원본(SVG·AI·고해상 PNG)이
있습니까?** 있으면 파일만 바꾸면 끝입니다.

### ⚠ 앞 문서의 「셋을 같이 뽑으십시오」는 제가 틀렸습니다

실제 참조를 세어 보니 이렇습니다:

    hero/look.png    index.html:63    쓴다
    hero/batch.png   batch.html:47    쓴다
    hero/scan.png    **아무도 안 쓴다** — index.html:59 주석이 설명만 한다
                     ("시안 화면2 것인데 우리에게 대응 화면이 없다")
    /guide           mascot.svg#ansimi-look — **이미 SVG 라 확대해도 선명하다**

**교체 대상은 `look.png` 하나**이고, `/batch` 히어로도 키울 거면 `batch.png`
까지 둘입니다. `scan.png` 는 손대지 않습니다.

## 5. 고친 뒤 다시 잽니다

    ① 8장 · 1440 / 1280 / 1024 / 768 / 390 다섯 폭
    ② 폭마다 `document.documentElement.scrollWidth > innerWidth` 가
       False 임을 **단정**한다 (§6 — 폭을 재는 캡처가 아니면 못 잡는다)
    ③ 캡처는 **장수가 아니라 높이**를 적는다. 같은 수가 반복되면 그게
       `full_page` 가 안 걸린 신호다
    ④ Pretendard 가 **실제로 받아졌는지** 확인한다 —
       `getComputedStyle(h2).fontFamily` 가 아니라 `document.fonts.check`
       또는 네트워크 응답으로. 폴백으로 떨어져도 fontFamily 문자열은 같다
    ⑤ 다크 모드에서 제목을 한 번 본다 — 굵기가 700 이 되면 다크에서
       번져 보일 수 있다

⚠ ④ 가 중요합니다. 이 저장소에서 *"받아 놓고 안 쓴다"* 가 이미 한 번
  났습니다 (README:205 — Noto Sans KR 을 받고 시스템 글꼴로 그리고
  있었습니다). **문자열이 아니라 실제로 그려지는 글꼴을 봅니다.**

## 6. 순서

    1. R4 표에 `cdn.jsdelivr.net` 을 적는다        ← 코드보다 먼저
    2. 검사를 좁힌다 + 반대 방향 확인
    3. 폰트를 넣는다 (링크 · --font-display · weight 700 자리들)
    4. 크기 네 곳 + 폰 분기
    5. 두 곳 갈림(.hero-say h1 / .intro h2)을 묶고 주석
    6. 다섯 폭 재측정 + ④ 글꼴 실제 수신 확인
    7. 커밋 — **한 단계 끝나면 다음을 건드리기 전에 커밋**
       (§6 "커밋 경계가 곧 복구 가능성이다")

⚠ 3과 4는 **따로 커밋**하십시오. 같이 넣으면 화면이 이상할 때 폰트 탓인지
  크기 탓인지 가를 수 없습니다.
