# 히어로 — 폰트는 받아도 됩니다. 제가 틀렸습니다

## 1. 먼저 정정합니다

지난 답에서 제가 이렇게 썼습니다:

> 폰트(Pretendard)는 README §3이 금지하고 검사가 잠갔다.

**틀렸습니다.** 규칙이 금지한 것과 검사가 잡는 것이 다른데, 제가 **검사를
규칙으로 읽었습니다.**

원문을 다시 봅니다.

    design/README.md:69
      공공 디자인 시스템 폰트(**Pretendard GOV**)는 쓰지 않는다

    sourcing_guard/static/app.css:38
      정부 식별 요소(KC 마크·정부 로고·**공공 디자인 시스템 폰트**)는
      가져오지 않는다

    tests/test_static_cache_and_font.py
      def test_the_body_font_is_the_token_and_the_gov_design_font_is_gone()
                                                 ^^^^^^^^^^^^^^^^
      """정부 디자인 시스템 폰트는 쓰지 않는다 — app.css 머리주석 원칙."""
      ...
      assert "Pretendard" not in code        ← 단정만 넓다

**규칙도, 주석도, 검사 이름도 전부 「GOV」·「공공 디자인 시스템 폰트」라고
적고 있습니다.** 단정 한 줄만 `"Pretendard"` 로 넓게 잡혀 있었고, 저는 그
한 줄을 보고 "금지됐다" 고 보고했습니다.

### 둘은 다른 글꼴입니다 — 확인했습니다

    Pretendard        SIL Open Font License
                      "글꼴 단독 판매를 제외한 모든 상업적 행위 및 수정,
                       재배포가 가능합니다" · 웹폰트 임베딩 지원(CDN 제공)
    Pretendard GOV    "대한민국 공공 서비스 환경에 적합" — 별도 변형판

출처: <https://github.com/orioncactus/pretendard>

우리가 막으려던 것은 **정부 식별 요소**이고, 그건 GOV 판입니다. 일반
Pretendard 는 그 이유에 해당하지 않습니다.

⚠ 이건 이 저장소가 이미 이름 붙여 둔 실패입니다 — CLAUDE.md §6:
*"R5(값을 지어내지 않는다)는 코드에만 적용되는 것이 아니다 — 문서의 서술도
확인 없이 근거로 쓰지 않는다."* 제가 그걸 했습니다.

## 2. 크기 — 시안을 재 보니, 우리가 이미 가지고 있습니다

시피님이 보내주신 시안 이미지를 픽셀로 쟀습니다 (이미지 폭 877px 기준,
1280px 로 환산).

| | 시안 이미지 | 환산 | 우리 `/scan` | 우리 랜딩 `/` |
|---|---:|---:|---:|---:|
| 제목 글자 높이 | 38–39px | — | — | — |
| **제목 font-size** | — | **약 59–60px** | **32px** | **60px** |
| 서브카피 | 13px | 약 20px | 19px | — |
| **마스코트 높이** | 154px | **약 225px** | **112px** | — |

교차 검증: 서브카피로 같은 환산을 하면 20px 이 나오고 우리 값은 19px 로
거의 일치합니다. 환산 배율이 맞다는 뜻입니다.

### 결론이 깔끔합니다

**`/scan` 히어로는 시안의 정확히 절반입니다. 제목도(32 vs 60), 마스코트도
(112 vs 225).** 그리고 시피님이 원하시는 60px 은 **우리 랜딩이 이미 쓰는
값입니다.** 새 눈금을 만들 필요가 없습니다.

⚠ 이건 CTA 에서 이미 한 번 적어 둔 원칙과 같은 자리입니다 —
`app.css:274` *"주 버튼은 랜딩과 같은 눈금이다 … 도구 화면만 56 이면 같은
제품이 두 벌로 보인다."* **버튼에는 적용했고 제목에는 안 했습니다.**

## 3. 세 가지 안 — `히어로_크기_3안.png`

같이 보내는 이미지에 세 안을 위에서 아래로 쌓았습니다. 전부 배포본에
실제로 그려 본 것입니다.

### A · 지금
제목 32px 고운돋움 400 · 마스코트 112px

### B · 크기만 올린다 — **폰트를 안 받습니다**
제목 60px 고운돋움 400 · 마스코트 225px
오늘 바로 됩니다. 값 세 개입니다. 다만 고운돋움은 **굵기가 400 하나뿐**이라
(`family=Gowun+Dodum` — 굵기 지정 없이 받고 있습니다) 시안의 굵은 제목은
나오지 않습니다.

### C · 크기 + Pretendard 700 — **시안에 가장 가깝습니다**
제목 60px Pretendard 700 · 마스코트 225px

### 제 권고는 **C** 입니다

대가가 하나 있습니다. 제목 글꼴을 고운돋움에서 바꾸는 것이고, 고운돋움을
고른 이유가 README:69 의 *"둥글고 부드러운 고딕 — 캐릭터와 같은 온도"*
였습니다.

**그런데 이번 변경이 마스코트를 112 → 225 로 두 배 키웁니다.** 캐릭터가
화면에서 차지하는 몫이 네 배가 됩니다(면적 기준). 온도를 **잃는 것이 아니라
글꼴에서 캐릭터로 옮기는 것**입니다. 그림이 그 일을 직접 하는데 글꼴이
대신할 이유가 줄어듭니다.

B 도 A 보다 확실히 낫습니다. 폰트 결정을 미루고 싶으시면 B 로 먼저 가고
C 는 나중에 얹어도 됩니다 — **B 에서 C 로 가는 데 되돌릴 일이 없습니다.**

## 4. 마스코트를 키우려면 — 자산이 먼저입니다

    현재 표시            132 × 112px
    현재 파일            /static/hero/look.png  =  112 × 113px (래스터)

거의 1:1 입니다. 225px 로 키우면 **2배 확대**라 뭉개집니다.

⚠ **그리고 지금도 이미 흐립니다.** 레티나(2x) 화면은 이 112px 원본을 224px
  로 그립니다. 시피님 화면에서 마스코트가 또렷하지 않았다면 그 이유입니다.

**벡터 원본이 저장소에 있습니다.**

    design/mascot-ansimi/mascot.svg
      id="ansimi-look"  ·  viewBox="0 0 130 162"

그리고 CSS 주석이 이 길을 **미리 설계해 뒀습니다** (`app.css:976`):

> *"원본(512px·SVG)이 오면 **파일만** 갈아 끼운다 - 마크업도 CSS 도 안 바뀐다."*

그대로 하면 됩니다 — SVG 에서 3배 해상도 PNG 를 뽑아 `look.png` 를 교체
하거나, SVG 를 직접 씁니다. 위 3안 미리보기의 마스코트는 **그 벡터 원본을
써서 그린 것**이라 이미지에서 보시는 선명도가 실제로 나오는 선명도입니다.

## 5. 잰 것과, 안 잰 것

### 잰 것 — 넘치지 않습니다

마스코트를 225px 로 키운 상태에서 다섯 폭을 쟀습니다.

    1440   마스코트 우측 1320 · 여유 120px   문서 가로 넘침 없음
    1280   마스코트 우측 1240 · 여유  40px   문서 가로 넘침 없음
    1024   마스코트 우측 1000 · 여유  24px   문서 가로 넘침 없음
     768   마스코트 없음 (.intro-art{display:none})
     390   마스코트 없음 (같은 이유)

⚠ **제가 미리보기 이미지를 보고 "오른쪽이 잘렸다" 고 읽었는데, 재 보니
  아니었습니다.** 눈으로 본 것을 그대로 적었으면 없는 결함을 보고할
  뻔했습니다.

### 안 잰 것 — 폰에서는 마스코트가 아예 없습니다

`app.css:1006` 이 768px 이하에서 `.intro-art{display:none}` 입니다. 시피님이
보신 시안은 데스크톱이고, **폰에서 이 큰 히어로를 어떻게 할지는 아직 정해진
적이 없습니다.** 세 갈래이고 이번 결정과 분리됩니다:

    (가) 폰에서도 계속 숨긴다        지금 그대로. 제목만 커진다
    (나) 폰에서 작게 되살린다        시안 §13 의 Mobile 48~72px
    (다) 폰에서는 제목 위에 얹는다   세로로 쌓는다

## 6. 시안 문서와 시안 이미지가 갈립니다 — 길은 있습니다

    시안 §13   Hero 96~140px 권고
    시안 §13   금지: "캐릭터가 텍스트보다 크게 보이는 구성"
    시안 이미지  마스코트 약 225px

**시안 이미지가 시안 문서를 넘습니다.** 둘 다 시피님이 주신 것이라, 어느
쪽이 기준인지는 제가 정할 수 없습니다.

다만 금지 조항은 **자동으로 풀립니다** — 마스코트만 225 로 키우고 제목을
32 로 두면 캐릭터가 텍스트보다 확실히 큽니다. 그런데 제목을 60px 두 줄로
같이 키우면 텍스트 덩어리가 약 150px 이 되어 균형이 잡힙니다.

**즉 「같이 키운다」가 조건입니다.** 마스코트만 키우면 걸리고, 둘을 같이
키우면 안 걸립니다. 3안 미리보기의 B·C 가 그 모습입니다.

⚠ §13 의 숫자(96~140)를 넘기기로 정하면 **문서에 적고 넘깁니다.** R5-b ③ —
  *"우리가 정하되 정했다는 사실과 근거를 같이 적는다."* 나중에 이 225 가
  시안 근거로 읽히면 안 됩니다.

## 7. 에이전트 지시

시피님이 A·B·C 중 하나를 고르신 뒤 넘깁니다. 아래는 **C 를 고른 경우**이고,
B 면 ②만 빼면 됩니다.

### ① 크기 — 랜딩 눈금을 가져온다

    app.css:222   .intro h2{font-size:32px}        → 60px · line-height:1.15
    app.css:223   .intro p{font-size:19px}         → 20px
    app.css:986   .intro-face.art{width:132px;height:112px}
                                                    → 180px × 225px

⚠ **새 값을 만들지 말고 랜딩이 쓰는 값을 확인해서 씁니다.** 랜딩 히어로는
  `app.css:675` 근처의 60px/72px 입니다. 두 곳이 갈리면 §6 의 "같은 판단을
  두 곳에 적지 마라" 가 또 발생합니다 — **가능하면 토큰이나 공용 클래스로
  묶고, 묶었으면 그 사실을 주석에 적습니다.**

⚠ `app.css:224` 의 640px 이하 분기(`.intro h2{font-size:24px}`)도 같이
  올립니다. 안 올리면 폰에서만 옛 눈금이 남습니다.

### ② 폰트 — Pretendard 를 제목에만

**받는 방법이 두 갈래입니다. 고르고 이유를 적으십시오.**

    (가) CDN        빠르다. 브라우저가 받는 곳이 하나 늘어난다
    (나) 자체 호스팅  호스트가 안 는다. README:70 이 이미 이 길을 예고했다 —
                    "본선에서 자체 호스팅으로 바꿀 수 있게 --font-* 변수
                     뒤에 폴백을 두었다"

⚠⚠ **(가)를 고르면 CLAUDE.md R4 의 「브라우저가 받는 곳」에 먼저 적습니다.**
  지금 둘입니다(`fonts.googleapis.com` · `fonts.gstatic.com`). R4 가 정해 둔
  판단 기준이 이미 있습니다 — *"투표 기간에 그 호스트가 죽으면 화면이 어떻게
  보이나. 폰트는 대체 글꼴로 떨어지므로 견딜 만하고, 스크립트는 아니다."*
  폰트이므로 통과합니다. **`ALLOWED_HOSTS` 에는 넣지 않습니다** — 그건 서버가
  나가는 곳이고 여긴 브라우저가 받는 곳입니다.

⚠ 미리보기에서 실제로 받아진 경로는
  `cdn.jsdelivr.net/gh/orioncactus/pretendard@v1.3.9/…` 입니다. **반영 전에
  현행 버전을 확인하십시오** — 제가 미리보기용으로 쓴 값이고 최신인지는
  확인하지 않았습니다 (R5).

적용 범위는 **제목·워드마크만**입니다. 본문은 Noto Sans KR 그대로:

    --font-display:"Gowun Dodum",…   →   "Pretendard",…  (굵기 700 사용)
    --font-body   그대로

### ③ 검사를 규칙에 맞춘다 — **이번 건의 뿌리입니다**

    tests/test_static_cache_and_font.py
      assert "Pretendard" not in code
    →  Pretendard GOV 만 막도록 좁힌다 (대소문자·공백 변형 포함:
       "pretendard gov" · "PretendardGOV" · "pretendard-gov")

그리고 **왜 좁혔는지 한 줄을 검사 옆에 적습니다.** 안 적으면 다음 사람이
"넓은 게 안전하다" 며 되돌립니다.

⚠ 반대 방향도 한 줄 재십시오(§6) — 좁힌 검사가 `font-family:"Pretendard GOV"`
  를 여전히 막는지 실제로 한 번 넣어 보고 확인합니다.

### ④ 마스코트 자산

`design/mascot-ansimi/mascot.svg` 의 `#ansimi-look`(viewBox 0 0 130 162)에서
뽑아 `sourcing_guard/static/hero/look.png` 를 교체합니다. 표시 225px · 레티나
2x 이므로 **최소 450px 높이**로 뽑습니다.

⚠ 나머지 히어로도 같은 상태입니다 — `scan.png` 179×132 · `batch.png` 140×124.
  **한 장만 고치면 화면마다 선명도가 갈립니다.** 셋을 같이 뽑으십시오.
