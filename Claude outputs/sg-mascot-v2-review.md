## 2. 돋보기 — 제가 접습니다. 이유를 적어 둡니다

§1-4 에 제가 이렇게 썼습니다: "체크·X·엄지·**돋보기**·방패 같은 판정·감시
기호는 어디에도 없다." 그리고 캐릭터 의뢰서 §3 에도 돋보기를 금지로 넣었습니다.

**다시 보니 그 목록에 돋보기가 들어간 건 제 과잉입니다.**

금지의 목적은 **"문장이 못 하는 주장을 그림이 해 버리는 것"** 을 막는
것이었습니다. 우리가 못 하는 주장은 넷입니다 — 안전하다 · 합법이다 ·
판매 가능하다 · 막아 준다.

    방패    "내가 막아 준다"      ✗ 금지 주장이다
    배지    "내게 권한이 있다"     ✗
    체크    "괜찮다"             ✗
    돋보기  "들여다본다"          ← **금지 주장이 아닙니다**

**"우리가 정부 원문을 조회했다" 는 우리가 할 수 있는 유일한 주장입니다.**
돋보기는 그 주장과 정확히 같은 말을 합니다. 게다가 제품 이름이 **안심 소싱
돋보기** 입니다 — 이름에 있는 것을 캐릭터에서 뺀 게 오히려 이상했습니다.

### 다만 지켜야 하는 선 하나

돋보기가 **캐릭터의 몸**인 것과, 캐릭터가 돋보기를 **상품에 들이대는** 것은
다릅니다. 앞은 "나는 들여다보는 존재" 고 뒤는 "내가 너를 검사한다" 입니다.

    ✓ 머리가 렌즈다 (지금 안)
    ✗ 상품·서류를 향해 돋보기를 겨누는 포즈
    ✗ 렌즈 안에 체크표시 · 렌즈에 "찾았다" 반짝임
    ✗ 검사관 · 탐정 소품 (모자 · 파이프 · 수첩)

이 네 줄을 §1-4 에 남겨 두세요. 금지를 지우는 게 아니라 **좁히는** 것입니다.

## 3. 크기·바탕 시험 — 제가 직접 재 봤습니다

시트의 '정상' 을 잘라내 **우리 실제 바탕 셋** 에 올려 4개 크기로 합성했습니다
(`sg-mascot-size-test.png`).

    바탕            88px    44px    32px    20px
    카드 흰색 #FFFFFF  좋음     좋음     읽힘     ✗ 뭉개짐
    크림 #FFF8F0      좋음     좋음     읽힘     ✗
    다크 #1D1917      좋음     좋음     읽힘     ✗ 흰 점

### 제 걱정 하나는 틀렸습니다

저는 "크림 몸통을 크림/흰 바탕에 올리면 형체가 안 보일 것" 이라고 볼 생각이
었습니다. **틀렸습니다.** 짙은 자주 테두리가 분리를 다 해 줍니다. 44px 결과
카드(흰 바탕)에서도 눈·입이 또렷합니다. 다크모드도 88·44·32 에서 괜찮습니다.

### 20px 은 실패합니다

렌즈 링 + 손잡이 + 팔 + 다리 + 바닥 그림자가 **한 덩어리로 뭉개집니다.**
다크 바탕에서는 흰 점 하나가 됩니다.

시트에는 "20px에서도 살아남는 것 — 윤곽 · 눈 · 입" 이라고 적혀 있는데
**실측은 그렇지 않습니다.** 같은 시트가 "20px용 별도 파일 제공 가능" 이라고
적어 뒀으니, 그건 **아직 안 온 납품물**입니다.

## 4. 디자이너에게 되물을 것 — 셋 + 시트 수정 셋

### 반드시 받아야 하는 것 (이게 없으면 적용 불가)

    ① **SVG 원본 5종 + 스프라이트.**
       받은 것은 래스터 이미지입니다. 헤더 32px · 파비콘 20px 을 PNG 로
       쓸 수 없고, 다크모드·고해상도 대응도 안 됩니다. 의뢰서 §7 항목입니다

    ② **20px 전용 단순화본.** 위 실측 근거를 같이 보내 주세요.
       살릴 것: 렌즈 링 · 눈 · 입
       뺄 것:   손잡이 · 팔 · 다리 · 바닥 그림자 · 홍조
       조건:    **같은 캐릭터로 보여야 합니다** (의뢰서 §5)
       ⚠ 32px 도 겸용으로 하나 더 받으면 좋습니다 — 32px 은 읽히지만
         다리·손잡이가 이미 뭉개집니다

    ③ **'주의' 와 '모름' 의 구분.**
       지금 둘 다 `?` 를 달고 있습니다. 검수 기준 ①이 "20px 에서 다섯
       표정이 구분되는가" 인데, 같은 소품을 쓰면 작은 크기에서 두 표정이
       한 표정이 됩니다. 그리고 실루엣 밖에 뜬 `?` 는 작은 크기에서 잘립니다.
       → 소품 대신 **눈·눈썹·입으로** 갈라 주세요

### 시트에서 고쳐야 하는 것 (캐릭터 문제는 아닙니다)

    ④ **결과 카드 목업의 문구·아이콘.**
       "조회 완료 / 확인 필요 / 데이터 없음" 은 우리 문구가 아닙니다.
       우리 것은 `SIGNAL_LABEL` — "확인된 문제 없음 · 확인 필요 ·
       확인 필요(중대) · 판단 근거 부족" 입니다. README §1-2 가 **디자인에서
       판정 문구를 새로 짓지 않는다**고 못 박아 둔 자리입니다.
       그리고 초록 원 아이콘이 재활용 기호처럼 보입니다 — 아이콘 세트는
       우리 것을 쓰거나 빼 주세요

    ⑤ **'확인 중' 표정.** 지금 `>_<` 로 **찡그린** 얼굴입니다.
       필요한 건 "지금 보고 있다" 이고, 힘주는 얼굴이 아닙니다.
       그리고 로딩 목업의 포즈(노트북)와 표정 시트의 '확인 중' 이 서로
       다릅니다 — 하나로 맞춰 주세요.
       ⚠ 노트북 소품은 88px 에서도 뭉개집니다. 권하지 않습니다

    ⑥ **워드마크.** 표지에 "안심 돋보기" 로 적혀 있습니다.
       제품명은 **안심 소싱 돋보기** 입니다 (시트 안 헤더 목업은 맞습니다)
