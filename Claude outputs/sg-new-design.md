# [총괄 판정] 새 시안 — **시각은 간다. 문구 셋은 못 간다**

시안을 열어 픽셀을 뽑아 색을 재고, 문구를 한 줄씩 우리 규칙과 대조했다.

---

## 0. 판정

    시각 방향        **좋다. 간다.** 지금 화면보다 낫다 (§3)
    ⛔ 문구 셋       **못 쓴다.** 디자인 문제가 아니라 제품 정체성 문제다 (§1)
    ⚠ 시안 한글      군데군데 깨져 있다. **옮겨 적지 마라** (§2)
    오늘            **토큰 교체.** 실측값 · 대비 전부 확인했다 (§4)
    본선            구조(3칸 요약 · 히어로 · 마스코트 재렌더) (§5)

## 1. ⛔ 못 쓰는 문구 셋

### (1) 「유해물질 — 적합 · 유해물질 기준을 통과했습니다」

**이건 절대 못 쓴다.**

우리는 시험성적서가 없다. 상세페이지 **글자**만 본다. 실제 함유량은
**원리적으로** 알 수 없다. 어젯밤에 밤을 새워 넣은 문장이 정확히 이거다.

    "실제 함유량은 상세페이지로 알 수 없습니다 — 공급처에 시험성적서를
     요청하세요."

이 시안을 그대로 올리면 **그 문장과 정반대를 같은 서비스가 말한다.** 그리고
심사위원이 "시험성적서 없이 통과를 어떻게 압니까" 라고 물으면 우리가 가진
모든 숫자가 그 자리에서 같이 죽는다.

### (2) 「리콜 — 없음 · 리콜 대상 상품이 아닙니다」

우리가 아는 것은 **"공표된 목록에서 일치하는 항목을 못 찾았다"** 이다.
"대상이 아니다" 는 그 상품의 **신분**에 대한 단정이고, 우리는 그걸 모른다.
아직 공표 안 됐을 수도 있고, 모델명 표기가 달라 못 찾았을 수도 있다.
CLAUDE.md R3-b 가 정확히 이 자리를 막는다.

### (3) 「이 상품, 안전한가요?」 + 「✅ 주요 항목이 모두 정상으로 확인되었습니다」

    §9 금지어      안전합니다 · 합법입니다 · 판매 가능합니다 · 문제없습니다
    design §1-4   체크 · X · 엄지 · 방패 같은 **판정·보증 기호는 어디에도 없다**

"안전한가요?" 를 묻고 초록 체크로 답하면 **"안전합니다" 라고 말한 것**이다.
글자로 안 썼을 뿐이다.

⚠ 랜딩의 **「사입해도 될까?」는 괜찮다.** 그건 셀러의 질문을 그대로 옮긴
  것이고, 우리는 답 대신 **찾은 것**을 보여 준다. "안전한가요?" 는 답이
  예/아니오로 나오는 질문이라 다르다.

## 2. ⚠ 시안의 한국어가 깨져 있다

    "포토레이트게 가스제"           → 프탈레이트계 가소제
    "섬밀성면부과 제2022-220호"     → 산업통상자원부고시
    "리를 데이트 / 리를 없음"        → 리콜
    "이 상품, 사업해도 될까?"        → 사입
    "어린이제품-공통안전기준 3.1.3"   → 조항 번호가 실제와 맞는지 미확인

**시안은 그림으로 보고 문구는 우리 것을 쓴다.** 이 글자들을 그대로 옮기면
법령 이름이 틀린 채로 공개된다 — 우리가 제일 못 하는 사고다.

(브랜드·모델명·제조국·강아지 사진도 전부 채움값이다. 당연히 실데이터로.)

## 3. 디자인은 살릴 수 있다 — **같은 그림, 우리 문장**

시안에서 제일 좋은 것은 **검사 항목 3칸 요약**이다. 셋을 한눈에 보여 주는
구조는 지금 우리 카드에 없고, 있어야 한다. 그대로 가되 **셋째 칸의 값만**
바꾸면 된다.

```
시안 (못 씀)                      우리가 할 수 있는 것

┌─────────────┐                ┌─────────────┐
│ KC 인증       │                │ KC 인증       │
│   적합        │                │   조회됨       │
│ KC 인증번호가   │                │ 인증번호가 조회되었습니다 │
│ 유효합니다      │                │ (인증상태: 적합)       │
└─────────────┘                └─────────────┘

┌─────────────┐                ┌─────────────┐
│ 리콜          │                │ 리콜          │
│   없음        │                │   일치 없음     │
│ 리콜 대상 상품이  │               │ 공표 목록에서 일치 항목을 │
│ 아닙니다       │                │ 찾지 못했습니다 (09-14까지)│
└─────────────┘                └─────────────┘

┌─────────────┐                ┌─────────────┐
│ 유해물질       │                │ 유해물질       │
│   적합        │  ⛔            │   기준 14건    │   ← 판정이 아니라 **수**
│ 유해물질 기준을   │               │ 적용되는 기준 14건. 함유량은 │
│ 통과했습니다     │                │ 시험성적서로 확인합니다     │
└─────────────┘                └─────────────┘
```

⚠⚠ **셋째 칸이 "14건" 이어도 그림은 안 약해진다.** 큰 숫자는 큰 낱말만큼
  강하고, 「적합」과 달리 **정보가 들어 있다.** 정직이 디자인을 깎지 않는다는
  증거가 이 칸 하나다.

⚠ 큰 제목 「이 상품, 안전한가요?」 자리는 **서버가 내려주는 headline 을
  그대로 넣는다.** 이미 신호별로 있고 §9 를 통과한 문장이다. 시안의 큰 제목
  처리(시각)는 그대로 쓰고 내용만 우리 것으로 채운다.

## 4. 오늘 하는 것 — **토큰 교체**

시안에서 픽셀을 뽑아 쟀다. 지금 팔레트는 **따뜻한 크림·갈색**이고 시안은
**차가운 라벤더·남색**이다. 방향이 반대라 색만 바꿔도 화면이 완전히 달라진다.

그리고 우리 토큰 체계는 이걸 위해 만들어져 있다 — `design/tokens.css` 한
곳을 고치고 `app.css` 로 옮기면 **일곱 화면이 한 번에** 따라온다.
`test_design_tokens.py` 가 두 파일을 대조한다.

## 시피님께

**시안 방향 좋습니다. 지금 화면보다 낫습니다.** 색을 픽셀에서 뽑아 재 보니
지금은 따뜻한 크림·갈색이고 시안은 차가운 라벤더·남색이라, 색만 바꿔도
화면이 확 달라집니다. 오늘 그것부터 하겠습니다.

**다만 문구 셋은 못 씁니다.** 특히 **「유해물질 — 적합 · 기준을 통과했습니다」**
는 절대 안 됩니다. 저희는 시험성적서가 없어서 함유량을 알 방법이 없습니다.
어젯밤에 "상세페이지로 알 수 없습니다" 를 넣으려고 밤을 샜는데, 같은 서비스가
다른 화면에서 "통과했습니다" 라고 하면 본선에서 첫 질문에 무너집니다.

**그런데 그것 때문에 디자인을 포기할 필요는 없습니다.** 시안의 3칸 구조를
그대로 쓰되 셋째 칸을 「적합」 대신 **「기준 14건」** 으로 두면 됩니다. 큰
숫자는 큰 낱말만큼 눈에 들어오고, 「적합」과 달리 **셀러에게 쓸모가 있습니다.**

그리고 시안의 한국어가 군데군데 깨져 있습니다 — "포토레이트게 가스제"(프탈
레이트계 가소제), "섬밀성면부과"(산업통상자원부고시), "리를"(리콜). 그림으로
보고 문구는 저희 것을 쓰겠습니다.
