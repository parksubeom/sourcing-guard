# P4 도매꾹 리스트 — **실제로 쳐 봤습니다. 됩니다**

시피님 컴퓨터에서 실호출로 끝까지 확인했습니다. 아래는 전부 실측입니다.

---

## 1. 이미지 — 넣습니다. 다만 방식만 약관대로

> **"상업적 이용 아니니까"**

이 경우엔 그 기준이 안 걸립니다. 약관이 **상업/비상업을 가르지 않고**
hotlink 자체를 막았기 때문입니다:

> "이미지 사용이 허용된 경우에는 제공된 이미지를 **다운로드 받아 사용하고
> 있는 이미지호스팅 서비스에 저장하여 사용**하시기 바랍니다."
> — <https://openapi.domeggook.com/main/guide/start>

그리고 **hotlink 는 우리에게도 불리합니다**:

    상품이 삭제되면        이미지가 깨진다 (도매꾹은 판매종료를 목록에서 뺀다)
    CDN 이 죽으면          카드가 빈 상자가 된다 — 투표 기간에
    R4 브라우저 호스트      처음으로 상거래 사이트가 하나 는다
    키로 관리받는 관계다    조건을 어기면 키가 막힌다. 그러면 전부 멈춘다

**받아서 저장하면 시피님이 원하신 화면이 그대로 나옵니다.** 잃는 것이
없습니다. 값도 작습니다 — 실측 원본이 120~207KB 이고, 200px 로 줄이면
장당 10~20KB, 30장에 **약 450KB** 입니다.

### 실측 ① 썸네일은 받아집니다

    50093564   179,842 바이트   받음
    41572803   207,403 바이트   받음
     6147209   121,554 바이트   받음

3/3 성공. CDN 은 `cdn1.domeggook.com`.

## 2. 목록 API 실측 — 빠르고 필드가 전부 있습니다

    getItemList  kw="완구" sz=5 so=rd
    → HTTP 200 · **0.338초** · 전체 28,632건 · 5,727페이지

받은 필드:

    no · title · thumb · url · price · unitQty · idxCOM · comOnly ·
    adultOnly · lwp · deli · market · **id**(판매자 — 저장 안 함)

    예) no 50093564
        title "pf 싸파리찐득이/4종/촉감완구/말랑이/kc인증"
        thumb https://cdn1.domeggook.com/upload/item/...
        url   http://domeggook.com/50093564
        price 975

    getItemView  multiple=true · 5건
    → HTTP 200 · **0.790초**   (100건까지 한 번에 됩니다)

## 3. ⚠ 중요한 실측 — 인증번호가 있는 상품이 3분의 1입니다

방금 완구 검색 5건은 **전부 인증번호가 비어 있었습니다.** 제목에 "kc인증"
이라고 적힌 상품인데도요. 그래서 우리 수집분 전체를 셌습니다:

    safetyCert 를 가진 상세          78건
      인증번호가 실제로 있는 것        52건 (67%)
      비어 있거나 "-"                 26건

    ⚠ 그 52건 중 상당수가 **전파인증**입니다 (`MSIP-CMI-…` · `R-R-…`).
      국표원 소관이 아니라 전파연구원이고, `build_cert_seed.py` 가 이미
      `CERT_NUMBER_RE` 로 거릅니다.

    국표원 형식 인증번호를 가진 것    24건  →  **78건의 약 31%**

### 그래서 무작위로 100개를 받으면 안 됩니다

30개쯤만 답을 받고 나머지는 "인증번호를 찾지 못했습니다"(AMBER)가 됩니다.

⚠ **그 AMBER 도 우리 서비스의 정상 결과입니다** — R3-b 대로 부재를 등급으로
  해석하는 것이고, 실제 도매꾹이 그렇다는 것을 보여주는 값이기도 합니다.
  다만 **화면이 전부 같은 색이면 클릭할 이유가 없습니다.**

### 큐레이션합니다 — 24~30개

    인증번호가 있고 조회되는 것     GREEN 이 나온다
    인증번호가 없는 것              AMBER — "찾지 못했습니다"
    규제 품목인데 번호가 없는 것     AMBER — 이쪽이 셀러에게 제일 쓸모 있다
    ⚠ 리콜 일치가 나오는 것          **리스트에 넣지 않는다** (아래 §4)

무작위보다 오히려 낫습니다 — 이미지 용량이 줄고(450KB), seed 조회 횟수가
줄고, 화면이 다양한 결과를 보여줍니다.

## 5. 에이전트 지시

### a. 수집 스크립트 — `scripts/build_showcase.py` (새로)

    ① getItemList 로 후보를 넉넉히 받는다 (카테고리 여럿 · so="rd")
       ⚠ 어린이제품·전기용품 쪽 카테고리를 섞는다. 인증 대상이라야 결과가 갈린다
    ② getItemView(multiple=true) 로 상세 — **100개씩 끊어서**
    ③ safetyCert 에서 국표원 형식만 추린다 (`CERT_NUMBER_RE` 재사용)
    ④ 24~30개를 고른다 — 있는 것 / 없는 것 / 규제품목인데 없는 것을 섞어서
    ⑤ 썸네일을 받아 **200px 로 줄여** `sourcing_guard/static/showcase/` 에 저장
    ⑥ 남길-목록 정제로 `data/showcase.json` 을 쓴다

⚠ ⑤ 에서 **원본을 그대로 커밋하지 마십시오.** 리포가 공개입니다. 줄인 것만
  넣고, 줄이는 크기를 스크립트에 적습니다.

⚠ ⑥ 의 정제 함수는 `domeggook_pii.write_sanitized()`(지울 목록)가 아니라
  `mfds_pii.py` 를 본보기로 **새 남길-목록 함수**입니다. 목록 밖 필드가
  디스크에 닿기 전에 버려져야 합니다 (CLAUDE.md §6).

### b. seed 에 넣는다

④ 에서 고른 상품의 국표원 인증번호를 `build_cert_seed.py` 경로로 조회해
`cert_seed.json` 에 더합니다. **클릭하면 반드시 답이 나오게** 하는 자리입니다.

⚠ 실호출입니다. 회차를 작업로그에 적습니다.

### c. 화면

    /showcase (또는 /scan 안의 한 구역)   카드 그리드
    클릭 → 기존 스캔 결과 화면을 그대로 쓴다 (새 결과 화면을 만들지 않는다)

⚠ 이 화면도 **가드 목록과 자료 칸 둘 다** 늘립니다. CLAUDE.md §6:
  *"화면을 하나 만들면 가드 목록 · 자료 칸 둘 다 늘린다."* `test_frontend`
  의 `PAGES` 에 넣고, `showcase.json` 도 문구 검사 대상에 넣습니다 —
  **자료에서 온 문구가 화면에 뜨는 것이 「우리가 틀린 것」 화면에서 이미
  한 번 났습니다.**
