## 0. 왜 뒤집는가 — 두 가지를 확인했다

### (1) 3칸 요약은 **CSS 뿐이다.** 데이터가 이미 있다

`index.html:837` 이 이미 이렇게 그리고 있다.

```js
data.axes.map(a =>
  '<div class="rv-ax">' +
    '<span class="n">' + a.name  + '</span>' +   // 인증 조회
    '<span class="v">' + a.label + '</span>' +   // 조회함 / 대조함 / 수록됨
    '<span class="m">' + a.note  + '</span>' +   // 2026-09-14 공표분까지 …
  '</div>')
```

그리고 `app.css:916` 의 `.rv-axes` 는 **이미 `repeat(3, 1fr)` 격자**다.
지금은 선으로 나뉜 납작한 띠로 그려져 있을 뿐이다.

**시안의 3칸 카드 = 이 격자에 배경·모서리·여백·아이콘 자리를 주는 것.**
JS 0줄 · 서버 0줄 · 새 문구 0개.

### (2) 동결 논리가 이 건에는 거꾸로 붙는다

동결의 근거는 "투표 중에는 지켜보는 사람이 없다" 였다. 그런데 지금 위험은
**지금 화면 그대로 15일을 노출하는 것**이고, 투표는 10/5 에 끝나 **되돌릴
기회가 없다.** 오늘은 사람이 지켜본다.

    되돌릴 수 있는 위험   오늘 배포하고 깨지는 것 → 커밋 하나 되돌리면 끝
    되돌릴 수 없는 위험   3초에 이탈하는 첫 화면으로 15일

**오늘 한다. 동결은 9/21 00:00 부터 그대로다.**

⚠ **되돌릴 자리를 먼저 적어 둬라.** 지금 배포본 `b12014cbb` 가 마지막
  정상이다. 무엇이 틀어져도 여기로 돌아온다.

## 3. B — 검사 항목 3칸. ⚠⚠ **선을 하나 지킨다**

`app.css:861` 에 이미 적혀 있는 규칙이다. **이 작업이 정확히 그걸 어길 자리다.**

> 주의: 축에는 **신호 색·체크를 칠하지 않는다.** `done` 은 "그 축을 했다" 지
> "그 축이 괜찮다" 가 아니다.

시안은 KC 인증에 초록 ✓, 값 글자를 초록·파랑·주황으로 칠했다. **그건 "확인함"
을 "괜찮음" 으로 바꿔 읽게 한다.** `_axes` 의 docstring 이 같은 말을 한다 —
*"✓ 를 크게 쓰면 셀러가 초록불로 읽는데 그게 우리가 회색불을 택한 이유다."*

### 그래서 이렇게 한다

    ✓ 간다   납작한 띠 → **카드 셋** (배경 · 모서리 --r-2xl · 여백 · 그림자 없음)
    ✓ 간다   `.n`(축 이름)을 작게 위로, `.v`(값)를 크게, `.m`(주석)을 아래 흐리게
    ✓ 간다   축 **종류**를 나타내는 중립 아이콘 (서류·목록·비커 같은 것)
             — 판정 기호가 아니다
    ✗ 안 간다 체크 · 초록/빨강 값 글자 · 카드 배경을 신호색으로 칠하는 것
    ✗ 안 간다 "적합" · "없음" · "통과" 로 값을 바꾸는 것 (§4)

지금 값은 서버가 이렇게 준다. **그대로 크게 쓴다.**

```
인증 조회   조회함 / 조회 실패 / 번호 없음
리콜 대조   대조함 / 일치 있음 / 조회 실패 / 대조 못 함
유해물질    수록됨 / 이 품목 미수록
```

### ⚠ 선택 — 셋째 칸에 수를 넣는 것 (**맨 마지막에. 초록이면**)

「유해물질 — 수록됨」은 셀러에게 아무것도 안 알려 준다. 시안이 거기에 값을
넣으려 한 직관은 맞다. 다만 「적합」은 못 쓰니 **수**를 쓴다.

```python
# scorer.py _axes ③
n = sum(1 for f in findings if f.kind is FindingKind.HAZARD_RULE_APPLIES)
hazard = (f"기준 {n}건", True) if n else ("이 품목 미수록", False)
```

⚠ 이건 **서버 변경**이다. A~F 를 다 끝내고 초록일 때만, **따로 커밋**해라.
  축 라벨을 단정하는 검사가 있으면 같이 옮긴다 — 새 값이 더 맞기 때문이다
  (§6: 검사는 지금 출력이 아니라 **옳은 것**을 적는다).
⚠ 판정 경로가 아니다 — findings 를 **세는 것**이고 signal 은 안 움직인다.
  그래도 다섯 숫자를 전/후로 확인해라.

## 4. 못 쓰는 문구 — 다시 적는다

시안을 보며 작업하다 보면 손이 간다. **셋 다 안 된다.**

    ✗ 유해물질 "적합 · 기준을 통과했습니다"   시험성적서가 없다. 알 방법이 없다
    ✗ 리콜 "없음 · 대상 상품이 아닙니다"      우리는 "목록에서 못 찾았다" 만 안다 (R3-b)
    ✗ "이 상품, 안전한가요?" + ✓            §9 · design §1-4

    ✓ 큰 제목 자리에는 **서버 headline** 을 넣는다. 신호별로 이미 있고
      §9 를 통과한 문장이다. 시안의 큰 제목 **처리**만 가져온다

⚠ 시안 한글이 깨져 있다 — "포토레이트게 가스제"·"섬밀성면부과"·"리를"·"사업해도".
  **그림으로만 보고 글자는 우리 것을 쓴다.**
