## 1. ⚠ 깨진 것 — 「지금 다시 검사」

`samples.js:90` 이 **`<a>` 에 `.btn-t` 를 붙였다.** `.btn-t` 는 `<button>` 용이다.

    ✗ text-decoration: underline   → 버튼 안 글자에 밑줄이 그어진다
    ✗ 세로 가운데 정렬 없음          → 60px 상자 **맨 위**에 글자가 붙는다

그래서 "테두리만 있고 글자가 위에 뜬 채 밑줄 그어진 것" 으로 보인다.
**이 페이지에서 제일 눈에 거슬리는 게 이거다.**

⚠ 실측으로 확인했다 — 저장소에서 `<a class="btn-t">` 는 **여기 하나뿐**이다.
  나머지는 전부 `<button>` 이라 멀쩡하다.

```css
/* app.css — .btn-t:hover 아래에 더한다 */
/* `.btn-t` 는 <button> 용이다. <a> 에 붙으면 밑줄이 남고 세로 가운데 정렬이
   안 된다 (2026-09-20 실측: /samples 의 「지금 다시 검사」 한 곳). 앵커에만
   건다 - <button> 들의 렌더링 경로를 건드리지 않는다. */
a.btn-t{
  display:inline-flex; align-items:center; justify-content:center;
  text-decoration:none;
}
```

⚠ **앵커에만 거는 것이 중요하다.** `.btn-t` 자체에 `display:inline-flex` 를
  걸면 `/scan`·`/watch` 의 멀쩡한 버튼 렌더링까지 바뀐다. 값에 비해 위험이 크다.

### 검사

    · `a.btn-t` 의 `text-decoration-line === "none"`
    · 글자 상자의 세로 중심 == 버튼 상자의 세로 중심 (±2px)
    · `/scan` · `/watch` 의 `button.btn-t` 높이 60px **그대로** ← 반대 방향

## 3. 마무리 안 된 것 (2) — 카드 안 무게가 뒤집혀 있다

지금 카드 머리가 이렇다.

```
[정상]
KC인증 정품 그로밋 인형 큰 대형 [40cm 월레스와그로밋 강아지 …]   17px · 진한 색 ← 제목처럼
소싱 가능 — 판매자 제공 정보 기준으로 …                        15px · 흐린 색 ← 부제처럼
```

**도매 상품명이 제목 자리를 먹고 있다.** 연관검색어를 다 붙인 이름이라 석 줄이
되고, 카드 열 개가 전부 키워드 덩어리로 시작한다. 정작 **셀러가 읽어야 할
한 줄 결론**이 부제로 밀려 있다.

무게만 뒤집는다. **DOM 은 안 건드린다 — CSS 만.**

```css
/* 상품명은 우리가 받은 **입력**이지 이 카드의 제목이 아니다. 제목 자리는
   한 줄 결론이 받는다. DOM 순서는 그대로 두고 무게만 바꾼다 - 상품명이
   위에 작게 오는 것은 눈표(kicker) 꼴이라 자연스럽다. */
.sx-head h2{font-size:14px; line-height:21px; font-weight:500; color:var(--fg-3)}
.sx-headline{font-size:17px; line-height:26px; color:var(--fg-1); font-weight:600}
```

⚠ **상품명을 자르지 마라.** 길어서 보기 싫지만 그건 **우리가 무엇을 넣고
  이 결과를 얻었는지**다. 감추면 이 페이지의 값이 준다. 작게 하는 것과
  숨기는 것은 다르다.
