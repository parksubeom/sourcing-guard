## 6. "확신 못 하는 것" 다섯에 대한 답

| 항목 | 답 |
|---|---|
| `INFO-000` 을 못 봤다 | **처리가 이미 맞다.** 모르는 코드는 성공이 아니므로 틀려도 멈춘다. 첫 성공에서 실제 코드를 보고 그 줄을 고칠 것 — 그때 커밋 메시지에 "관례값 → 실측값" 을 적는다 |
| 봉투 경로·페이지 상한·총건수 미확인 | 당연하다. 오류 응답만 받았다. `rows_of()` 가 경로를 **찾아서 어디서 찾았는지 함께 돌려주는** 설계라 첫 성공에서 그대로 드러난다. R5 대로다 |
| 키가 샘플인지 정식인지 | 위 4절 2회 판별 |
| 주소 패턴이 "시/도 … 구/군" 만 본다 | 맞다. `ADDR` 은 남길 목록 밖이라 애초에 안 들어온다. 이건 자유 텍스트에 섞여 든 주소만 잡는 그물이고, 그물은 성길수록 오탐이 적다 |
| `BSSHNM`(업소명)을 남김 | **유지한다.** 제3자 정보지만 법인명이고, `MAKER_OTHER_RECALLS`(같은 제조사의 다른 리콜)가 이 값을 쓴다 — 셀러가 공급처를 보는 유일한 신호다. 개인 사업자명이 섞여 들 수 있다는 것은 첫 성공 수집에서 **실측으로 세어** 볼 것 |
