## 5. 새 규칙 — `git ls-files` 를 쓰는 검사는 **커밋 전 파일을 못 본다**

"커밋 후 한 번 더 돌린다" 는 사람의 기억에 기대는 규칙이라 반드시 샌다.
검사 자체를 고치는 편이 낫다:

    git ls-files                                  추적 중인 파일
  ∪ git ls-files --others --exclude-standard      아직 추적 안 되는(무시 대상 아닌) 파일

둘의 합으로 훑으면 **새 파일이 커밋 전에도 잡힌다.** 오늘 겪은 그 상황이 처음부터
빨갛게 났을 것이다. §6 에 한 줄로 적을 것 —
`git ls-files` 로 리포를 훑는 검사는 `--others --exclude-standard` 도 함께 본다.

⚠ 커밋 메시지의 실호출 "12회" 는 **고치지 않는다.** 그때 잰 수의 기록이고, 정정은
  작업로그에 적는다(옛 해시를 안 고치는 것과 같은 이유). 실제 17회 —
  성공 13(lawSearch 2 · lawService 11) · 실패 4.
