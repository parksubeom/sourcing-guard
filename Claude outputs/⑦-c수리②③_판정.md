## 2. ⚠⚠ 주소 빈틈 — 재 봤다. **닫을 수 있고, 실측이 끝났다**

> "주소 그물의 알려진 빈틈 셋은 고치지 않았습니다 — 지금 자료 376건에 잔존 0 이라
> 미뤘습니다."

판단이 조심스러운 방향이라 나쁘지 않다. 그런데 **재 보니 닫힌다.**

### 먼저 — 내 첫 판이 틀렸다

"시도를 선택으로 바꾸면 된다" 고 생각하고 쳐 봤다. 알려진 케이스는 전부 통과했는데
**실측 376행에서 오탐 5건**이 났다:

    ⚠ (314~318) DISTBTMLMT = "제조일자 표시 식품으로 해당사항 없음"
       표시(시로 끝남) + 식품으로(로로 끝남)  →  '시군구 + 도로명' 으로 읽혔다

**황색포도상구균과 똑같은 모양이다.** 네 조심이 옳았다 — 순진하게 느슨하게 하면
다른 오탐이 들어온다.

### 두 갈래로 가르면 닫힌다

행정구역 이름은 **접미사 앞이 최소 두 글자**다(강남구·분당구·성남시·구례군).
`표시` 는 한 글자다. 다만 `부산 중구`·`서울특별시 중구` 처럼 한 글자 구가 실재하므로
시도가 있을 때만 한 글자를 허용한다.

    시도가 있으면   시군구 1자 이상 허용   (부산 중구 중앙대로)
    시도가 없으면   시군구 **2자 이상** 요구 ('표시' 를 배제)

### 실측 — 전부 통과

    빈틈 셋      성남시 분당구 판교로 / 경기 성남 분당구 판교로 / 경기도성남시 분당구 판교로
                → **셋 다 잡힌다**
    기존 유지    경기도 성남시 분당구 판교로 · 서울 강남구 테헤란로 · 충남 아산시 배방읍 ·
                경기 광주시 곤지암읍 · **부산 중구 중앙대로** · **서울특별시 중구 세종대로**
                → **여섯 다 유지**
    오탐 금지    황색포도상구균 ×2 · 전남 구례군 산수유 · 제주 감귤 · 동결건조 ·
                작동 불량 · 도라지청 · 시금치 · **제조일자 표시 식품으로**
                → **아홉 다 안전**
    실측 376행   **잔존 0건**

    어긋난 케이스 0

### 판단 — **프리즈 전에 넣는다**

    · 개인정보 축이다. 놓치면 되돌릴 수 없다 (네가 주석에 고쳐 적은 그대로)
    · 측정이 끝났다. 남은 것은 정규식 한 줄과 `_KNOWN_GAPS` 를 정상 검사로 옮기는 일
    · 30분이고 판정 경로를 안 건드린다

⚠ 옮길 때 `_KNOWN_GAPS` 를 **지우지 말고** "이제 잡는다" 쪽으로 뒤집을 것 —
  셋이 왜 빈틈이었는지가 기록이다.

## 3. "확신 못 하는 것" 넷에 대한 답

### ① `SECRET_SETTINGS` 가 이름 규칙(`*_key`·`*_token`)으로 가린다

**닫힌 목록을 양쪽에 두면 이름 규칙이 필요 없다.**

    SECRET_SETTINGS   시크릿인 필드
    PUBLIC_SETTINGS   시크릿이 아닌 필드
    검사: Settings 의 모든 필드가 **둘 중 하나에** 있어야 한다

이러면 `credential` 이든 뭐든 **새 필드를 넣는 순간 분류를 강제당한다.** 이름을
맞힐 필요가 없어진다. ⑦-a 의 "예시가 괄호 안에서만 나오면 뺀다" 와 같은 모양이고,
이 리포가 이미 세 번 쓴 패턴이다.

### ② README 사본 가드가 첫 문단 지문을 쓴다

**더 나은 안이 나에게도 없다.** 숫자로 거르는 방법을 생각해 봤는데,
`70.4%`·`83.7%` 는 기획서·CLAUDE.md·판정 문서에 **역사로서 정당하게** 남아 있다
(확인함 — 다섯 파일). 문자열 금지는 못 쓴다.

대신 **원인을 줄이는 쪽**이 낫다 — 아래 §4.

### ③ 제출문 가드가 존재만 본다

**부정 단언을 하나 더 붙일 것.** 진위는 검사가 못 하지만, **이미 틀렸던 그 문장**이

## 4. ⚠ `Claude outputs/제출폼_붙여넣기.md` 하나는 빼야 한다

판정 문서 8개를 "지시 기록이라" 유지한 판단은 받는다. 그런데 **이 한 파일은
판정 기록이 아니다:**

    · **제출 답안 본문**이 그대로 들어 있다 (공개 저장소다)
    · 「쓰지 말 것」 절 — "고객·파일럿·LOI 를 암시하는 표현 — 없습니다" 같은 작업 메모
    · 그리고 **세 번 낡았다** — 394자판·모델명 포함판이 남아 있고, 지금 쓰는 것은
      497자판이다

심사위원이 리포를 열면 **제출 답안의 옛 판과 "이렇게는 쓰지 마라" 목록**을 같이 본다.
부정직한 내용은 아니지만 — 오히려 과장을 막는 내용이다 — 공개 리포에 둘 이유가 없다.

    git rm --cached "Claude outputs/제출폼_붙여넣기.md"

⚠ 히스토리는 건드리지 않는다. 키도 개인정보도 없다.
