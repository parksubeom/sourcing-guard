## 총괄이 먼저 틀렸습니다

에이전트가 ③에서 *"자산이 작아서 225 가 안 된다는 제 보고가 틀렸습니다"*
라고 적었는데, **그 틀린 치수를 제가 먼저 줬습니다.**

`sg-hero-size.md` §7 ①에서 제가 이렇게 적었습니다:

    .intro-face.art{width:132px;height:112px} → 180px × 225px
                                                 ^^^^^^^^^^^^

**180×225 는 제가 틀린 그림으로 만든 값입니다.** 3안 미리보기를 만들 때
`mascot.svg#ansimi-look`(130×162 세로형)을 썼는데, `/scan` 의 실제 자산은
`hero/look.png`(112×113, 거의 정사각)입니다. 세로형 비율에 맞춘 칸을
정사각 그림에 씌우니 가로가 먼저 걸린 것이고, 그래서 "자산이 작다" 는
결론이 나왔습니다.

그 다음 문서(`sg-hero-c-order.md`)에서 225×225 로 고쳐 적었지만, 첫 값이
이미 나간 뒤였습니다. **에이전트가 자기 탓으로 적은 것의 뿌리는 제 쪽입니다.**

## ⚠ 어긋난 것 하나 — 굵기가 화면에 안 닿습니다

    CSS 파일        .intro h2{ … font-weight:700 … }   (app.css:240)
    실제 화면        font-weight **400**

**소스만 읽으면 700 이라 안 보입니다.** 뒤에 같은 선택자가 한 번 더 있고,
그쪽이 이깁니다:

    240줄   .intro h2{ … font-weight:700; … }              ← 고쳤다
    591줄   h1, h2, .wordmark, .intro h2{ font-weight:400 } ← 안 고쳤다. 뒤라서 이긴다

같은 명시도면 **나중에 선언된 것**이 이깁니다.

### 증거 — 같은 제품에서 갈렸습니다

    /        .hero-say h1   60px · weight **700**   ← 697줄. 591줄보다 뒤라서 이긴다
    /scan    .intro h2      60px · weight **400**   ← 240줄. 591줄보다 앞이라서 진다
    /batch   .intro h2      60px · weight **400**

**랜딩만 굵고 도구 화면은 가늘습니다.** 시피님이 고른 C안은 700 이고,
지금 화면은 B안(고운돋움 400)에서 글꼴만 바뀐 모습입니다.

⚠ 그리고 **987줄 주석이 지금 사실과 다릅니다** —
  *"굵기는 위 `.intro h2` 가 700 으로 정한다"*. 실제로 정하는 것은 591줄입니다.

### ⚠⚠ 이건 이 저장소가 이미 이름 붙여 둔 자리입니다

CLAUDE.md §6:

> *"**주입**으로 잰 CSS 값을 「검증했다」고 말했다 (파일을 고치면 **순서 때문에
> 다른 값이 나온다** - 실제로 108px 이 나왔다)"*

> *"화면 검사는 틀이 아니라 **틀에 붓는 값**을 본다."*

그때는 108px 이었고 이번엔 weight 400 입니다. **소스를 고친 것과 화면이
그렇게 그려지는 것은 다릅니다.**

## 할 일

### ① 591줄에서 굵기를 뺀다

    591줄   h1, h2, .wordmark, .intro h2{
              font-family:var(--font-display);
              font-weight:400;      ← 이 줄이 문제
            }

⚠ 그냥 700 으로 바꾸지 마십시오. 이 규칙은 `h1`·`h2`·`.wordmark` 를 **전부**
  묶고 있어서, 700 으로 바꾸면 이름 모를 다른 제목들이 같이 굵어집니다.

**`font-weight` 선언 자체를 빼고 각 규칙이 정하게** 하는 쪽을 권합니다.
그러면 240줄의 700 과 697줄의 700 이 그대로 살고, 굵기를 안 적은 제목들은
브라우저 기본(h1·h2 는 bold)을 받습니다.

⚠ **빼고 나서 다른 제목들이 어떻게 되는지 같이 재십시오.** 지금 400 에
  기대고 있던 자리가 있을 수 있습니다 — 8화면에서 `h1`·`h2`·`.wordmark` 의
  computed weight 를 **전부 찍어서 표로** 주세요. 몇 개를 봤는지 같이
  적습니다 (§6 "완전성 검사는 몇 개를 봤는가를 같이 단정한다").

### ② 987줄 주석을 사실에 맞춥니다

무엇이 굵기를 정하는지 다시 적으십시오. 고친 뒤의 사실로요.

### ③ 검사를 붙입니다 — **computed 로**

지금 검사 1,800개가 이걸 못 잡았습니다. 소스 문자열만 보기 때문입니다.

    화면을 실제로 띄워 computed font-weight 를 단정한다
    /(랜딩)과 /scan 의 히어로 제목이 **같은 값**임을 단정한다
    ⚠ 본 화면 수를 같이 단정한다 (assert len(checked) == N)

⚠ 이 검사가 있었으면 이번 건이 배포 전에 걸렸습니다.
