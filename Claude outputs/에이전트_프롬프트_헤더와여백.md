# 에이전트에게 — **앞서 보낸 `h1` 프롬프트에 이어서**

⚠ 순서가 바뀝니다: **① `h1`(기존) → ② 헤더 내비(새로) → ③ 랜딩 여백 +
히어로 이관(같이)**

---

## ⚠⚠ 총괄이 틀렸습니다 — "헤더 8장 전부 같음" 은 **높이와 개수만** 잰 것

어제 제가 이렇게 보고했습니다:

> *"헤더 `masthead` **65px · 내비 5개** — 8장 전부 같음"*

**높이와 링크 개수만 쟀고 「위치」를 안 쟀습니다.** 실제로 재 보니 갈립니다.

    ⚠ 이것이 세 번째입니다 — 히어로를 「크기」만 재고 태그를 안 봤고,
      헤더를 「높이·개수」만 재고 위치를 안 봤습니다. 어제 §6 에 넣은
      *"세기 전에 무엇을 셀 것인가를 먼저 적는다"* 를 총괄이 계속 밟습니다.

---

## [②] 헤더 내비가 **세 위치**에 있습니다

    화면                        내비 좌  내비 우  내비폭  배지폭
    /  /scan  /watch            596    1086    490    126
    /samples  /misses  /unknown  572    1086    **514**  126
    **/batch  /guide             750    1240**   490      0

### 원인 둘 (실측)

**(a) 배지가 없으면 내비가 154px 오른쪽으로 갑니다** — `/batch`·`/guide`

배지를 안 다는 것은 **설계가 맞습니다**(그 둘은 리콜을 대조하지 않으므로
기준일 배지를 달면 대조한 것처럼 읽힙니다 — 기존 검사가 강제합니다).
**설계는 그대로 두고, 자리만 지킵니다.**

    배지 자리를 **폭 126px 로 고정**합니다 (내용이 없어도)
    ⚠ `display:none` 이 아니라 자리를 남기는 방식으로
      (`visibility:hidden` · 빈 자리 확보 · `min-width` 중 하나)
    ⚠ 스크린리더가 빈 요소를 읽지 않게 하십시오

**(b) 「소개」 링크 폭이 28px 과 52px 로 갈립니다** — ±24px

    /  /scan  /batch  /guide     소개 **28px**
    /samples  /misses  /unknown  소개 **52px**
    (나머지 네 항목은 84·84·84·98 로 전부 같습니다)

⚠ **28px 은 한글 두 글자에 좁습니다**(15px 폰트면 최소 30px). 압축됐거나
  스타일이 갈린 것입니다. **원인을 찾아 적으십시오** — 총괄은 현상까지만
  쟀습니다.

### 검사

    8장의 **내비 좌표(left·right)가 같은지** 단정
    ⚠ 높이·개수가 아니라 **위치**입니다. 그것이 이번에 빠진 축입니다
    ⚠ 본 화면 수를 같이 단정

## [③] 랜딩만 상단 여백이 **112px** 입니다

    화면        헤더→첫 글자   히어로 top   히어로 padding-top
    **/          112px       105px      0px**
    /scan        32px        65px       32px
    /batch       36px        65px       32px
    /watch       42px        65px       32px
    /guide       58px        65px       32px
    /samples     32px        65px       32px
    /misses      32px        65px       32px
    /unknown     42px        65px       32px

**헤더 바닥이 65px 인데 `.lv2-hero` 가 105px 에서 시작합니다 — 사이 40px 이
비어 있습니다.** 그리고 `.lv2-hero` 자체 패딩은 0 이라, 첫 글자까지 112px
입니다. 나머지 일곱 장은 32~58px 입니다.

시피님이 캡처로 지적한 자리이고, **실측이 맞습니다.**

⚠ **`/guide` 58px · `/watch`·`/unknown` 42px 도 나머지(32px)와 다릅니다.**
  큰 차이는 아니지만, 히어로를 `layout.py` 로 옮기면 **이것도 같이 하나가
  됩니다.**

### 그래서 ③은 히어로 이관과 **같이** 하십시오

앞 프롬프트의 ②(히어로를 `layout.py` 로)를 할 때, **랜딩 여백도 그 안에서
정리됩니다.** 따로 고치면 두 번 만지게 됩니다.

    ⚠ 다만 랜딩 `.lv2-hero` 는 **구조가 다릅니다**(789px · 마케팅 화면).
      `layout.py` 로 옮기는 것은 `.intro` 7장이고, **랜딩은 여백만**
      맞추십시오 — 히어로 자체를 `.intro` 로 바꾸지 마십시오

    맞출 값: 헤더 바닥 → 첫 글자까지 **8장 동일**
    ⚠ 랜딩은 히어로가 커서 위가 비어 보입니다. 32px 이 적절한지 **캡처로
      보고 정하십시오** — 값을 제가 지정하지 않겠습니다. 재고 정하는 것이
      맞습니다

### 검사

    8장의 「헤더 바닥 → 히어로 첫 글자」 거리가 같은지
    ⚠ 본 화면 수 단정

## 순서

    ① `h1` 세 줄            (앞 프롬프트) → 배포 → 확인
    ② 헤더 내비 위치         → 배포 → 확인
    ③ 랜딩 여백 + 히어로 이관  → 배포 → 확인

**묶지 마십시오.** ②는 헤더만, ③은 히어로만 건드립니다 — 문제가 나면
어느 쪽인지 바로 압니다.
