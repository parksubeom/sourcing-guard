## 1. 기록에서 읽히는 이유 — 다만 추정입니다

명시된 결정은 못 찾았고, 가까운 근거가 둘 있습니다.

**① 핸드오프:101** — 크롬 확장을 뺀 이유를 적으면서:

> *"(2) **3~4일이 그대로 프론트엔드로 간다.**"*

프런트에 쓸 시간이 없다는 인식이 그때 있었습니다.

**② 핸드오프:197** — 인수 시점 진척도: *"프론트엔드(**0%**)"*

**③ CLAUDE.md §8** — 20일 제약과 스코프 방어선. 버리는 순서가 정해져 있고,
프런트 프레임워크는 그 목록에 없지만 같은 압력을 받았습니다.

⚠ **이것들은 정황이지 결정문이 아닙니다.** "Next.js 를 쓰지 않기로 했다"
  라고 적힌 줄을 저는 못 찾았습니다.


## 1-b. 시점까지 좁혔습니다 — **일정보다 9일 일찍, 다른 방식으로**

    2026-09-01 작업로그   "**프론트엔드 0%** — §8 일정상 **9/13~9/17 (5일 통째로)**"
    2026-09-04 작업로그   "화면 중복 검사 — **정적 HTML 까지만** 넓혔다.
                          세 화면의 마크업에…"

**9/1 에는 「프런트는 9/13부터 5일」이 계획이었고, 9/4 에 이미 정적 HTML
화면 셋이 있어 검사가 그것을 훑고 있었습니다.**

즉 계획된 5일을 쓰기 전에, **9일 일찍 다른 방식으로 화면이 생겼습니다.**
그리고 **그 전환을 적은 줄이 없습니다.**

⚠ 이것은 나쁜 일이 아닙니다 — 빨리 움직인 것이고, 그 덕에 남은 시간이 규칙
  DB 와 측정에 갔습니다. **다만 「왜」가 기록되지 않았습니다.**

## 3. 그래도 얻은 것 — **그리고 이게 큽니다**

    빌드가 없다        `fly deploy` 한 번. node 툴체인 · 번들러 · 잠금파일 0
    의존성이 적다       공격면과 유지 비용이 작다
    **검사가 파일을 직접 읽는다**

⚠⚠ **마지막이 이 프로젝트의 핵심입니다.**

이 저장소의 화면 가드 — `srccheck.markup_only` · 이모지 가드 · 단정 표현
가드 · 문구 완전성 검사 — 는 **HTML 을 문자열로 읽습니다.** 오늘만 해도
이 검사들이 잡은 것이:

    「잠시 후」가 축 카드에 남아 있던 것
    `(주)` 법인 표기가 화면으로 나가는지
    §9 고지문이 여덟 장에 있는지
    Pretendard GOV 가 코드에 들어왔는지

React/Next 였으면 이것들을 **렌더해서** 봐야 합니다. 검사가 무거워지고,
"틀이 아니라 틀에 붓는 값을 본다" 가 훨씬 어려워집니다.

**스택 선택이 검사 전략을 낳았고, 그 검사가 오늘 여러 번 결함을 잡았습니다.**

## 4. 지금 바꾸는가 — **아니요**

    `layout.py` 가 중복을 없앱니다  오늘 하는 작업이 그것입니다
    검사 1,855개가 HTML 전제입니다  옮기면 검사 전략을 다시 만들어야 합니다

그 검사들이고, 스택을 바꾸면 **지키는 장치부터 다시 만들어야 합니다.**
얻는 것(DX)보다 잃을 수 있는 것(가드)이 큽니다.

## 5. ⚠ 고쳐야 할 것 — 기획서

**투표 중에도 이건 고쳐야 합니다.** 코드가 아니라 문서이고, 화면에 안
닿으며, **제출물이 지금 사실과 다릅니다.**

      PostgreSQL/SQLite      → SQLite

    §5 **모델 구성** 문단
      "Claude 단일 모델"      → **GPT 한 벌**(`gpt-5.4-mini`)
      ⚠ 이유도 바뀌었습니다. 그때는 "프롬프트 두 벌 관리 여력 없음" 이었고,
        지금은 R7 이 적은 **"죽은 2순위는 안전망이 아니라 문서의 거짓말"**
        입니다. **옛 이유를 지우지 말고 개정 이력으로 남기십시오** —
        R7 이 그 모양으로 되어 있습니다

⚠⚠ **그리고 Next.js → HTML 전환 기록을 만드십시오.** 지금 없습니다.
  "왜 안 썼는가" 에 대한 답이 저장소 어디에도 없으면, 6개월 뒤 누군가
  "기획서대로 Next.js 로 옮기자" 고 할 때 막을 근거가 없습니다.
  **§3 에 적은 세 가지(빌드 없음 · 의존성 · 검사가 파일을 읽는다)가 그
