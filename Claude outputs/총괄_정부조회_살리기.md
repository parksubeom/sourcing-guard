# 정부 조회 — **안 재본 축이 하나 남아 있습니다. 오늘 밤에 됩니다**

## 0. 답

**네, 살릴 수 있습니다.** 그리고 가장 싼 길이 아직 안 재본 자리에 있습니다 —
**코드 변경 0 · secret 한 줄 · 1분.**

## 1. 우리가 잰 것과 안 잰 것

세 번 쟀는데 **전부 같은 축**이었습니다:

    P1 회차1   connect 8    → 실패
    P1 회차2   connect 10   → 실패
    P1 회차3   connect 30   → 실패
                ^^^^^^^^^ 전부 **시간** 축

**포트·프로토콜 축은 한 번도 안 쟀습니다.**

### ⚠⚠ 배포본은 지금 **HTTP(포트 80)** 으로 나갑니다

    sourcing_guard/data/kats_field_map.yaml:83
      base_url: "http://www.safetykorea.kr/openapi/api"
                 ^^^^

`.env` 의 `KATS_BASE_URL` 은 **빈 값**이라 이 매핑 기본값이 쓰입니다.

그리고 제가 "한국에서는 된다" 고 잰 것은 **`https://www.safetykorea.kr/`**
— **다른 포트였습니다.** 비교가 어긋나 있었습니다. 제 잘못입니다.

## 2. 방금 한국에서 잰 것 — **https 로도 API 가 됩니다**

    http://www.safetykorea.kr/openapi/api    → 레코드 있음 · 적합 · 0.53s
    https://www.safetykorea.kr/openapi/api   → 레코드 있음 · 적합 · 0.56s

같은 인증번호(`CB061R2170-3018`)로 실제 `lookup_certification` 을 쳤고
**둘 다 정상**입니다. 연결도 둘 다 0.034~0.036초입니다.

⚠ 이건 한국 기준입니다. **도쿄에서 443 이 되는지는 아직 모릅니다** —
  그것이 재야 할 것입니다.

## 3. 왜 이 축을 의심하지 않았나

**우리 안에 「정부 API 는 http」라는 인상이 있었습니다.** CLAUDE.md R4 가
식약처에 대해 이렇게 적어 뒀습니다:

> *"**HTTPS 가 안 된다**(총괄 실측: https → connection reset ×2 · http → 200)"*

그 경험이 국표원에도 적용된다고 **아무도 확인하지 않고** 믿었습니다.

⚠⚠ **§6 이 이름 붙인 그 패턴입니다** — *"주석이 걱정한 방향은 막혀 있었고,
  안 적은 반대 방향이 뚫려 있었던 것이 네 번이다."* 우리는 시간 축을 세 번
  쟀고 포트 축을 한 번도 안 쟀습니다.

# 에이전트에게 — [P5] 먼저, P6 는 그 다음

## [P5] https 로 한 번 재 주세요 — 코드 변경 0

    fly secrets set KATS_BASE_URL="https://www.safetykorea.kr/openapi/api"
    → 배포 완료 후 POST /api/v1/sync 를 친다
    → /healthz 의 kats 를 본다

`settings.kats_base_url` 이 **이미 매핑 기본값을 덮는 구조**입니다
(`kats_client.py:501` — `base_url or self._map.get("base_url")`). 코드를
건드리지 않습니다.

### 적을 것

    친 시각(UTC) · 전체 시간 · last_error_code · errors 원문
    성공했으면: 몇 초 · new 몇 건 · last_success_at

### 세 갈래

    ① 된다        **끝났습니다.** secret 을 유지하고, 매핑 기본값도 https 로
                 바꾸고(둘이 갈리면 §6), 리콜 사본이 채워지는 것을 확인합니다.
                 P6·플랫폼 이전 전부 불필요해집니다
    ② 안 된다      포트 축도 죽습니다. 그러면 P6(리전)가 다음입니다
    ③ 다른 오류    `network.connect` 가 아닌 것이 나오면(TLS·인증서·리다이렉트)
                 **그것 자체가 진전입니다** — 연결은 됐다는 뜻이니 적어 주세요

⚠ **실패하면 secret 을 unset 해서 되돌리십시오.** P1 때와 같은 이유입니다.

## [P6] 리전 시험 — **이제 둘을 같이 잽니다**

sin · syd 에서 **http 와 https 둘 다**:

    curl -o /dev/null -w "%{http_code} connect=%{time_connect}" --max-time 20 \
         http://www.safetykorea.kr/openapi/api
    curl -o /dev/null -w "%{http_code} connect=%{time_connect}" --max-time 20 \
         https://www.safetykorea.kr/openapi/api

⚠ 404 가 나와도 **연결은 성공한 것**입니다 (한국에서도 404 입니다 — 경로에
  파라미터가 없어서). 보는 것은 `time_connect` 와 **timeout 이 아닌지** 입니다.

⚠ 별도 앱 · `fly machine run <image> <명령>` 위치 인자 · 재고 나서 삭제.

## 남은 갈래 (P5·P6 가 둘 다 실패했을 때만)

    한국 중계     `KATS_BASE_URL` 이 이미 설정이므로 **secret 한 줄**로 붙는다.
                 코드 변경 0. 공개 IP 가 있는 곳이어야 한다
    플랫폼 이전    마지막. Vercel 은 영속 볼륨·백그라운드 루프가 없어
                 저장 구조부터 다시 설계해야 한다
