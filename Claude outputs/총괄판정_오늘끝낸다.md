# 총괄 판정 — **오늘 끝냅니다. 제가 과했습니다**

## 0. 제 판정을 뒤집습니다

제가 "미룬다" 를 세 번 적었습니다. 그런데 **P4 에는 이렇게 썼습니다**:

> *"투표 첫날에 올리는 것이 마지막날보다 낫습니다 — 노출 기간이 깁니다.
> 되돌리기도 라우트 제거 한 번입니다."*

**같은 논리인데 UI 에는 적용하지 않았습니다.** 일관성이 없었습니다.

그리고 "미룬다" 의 근거를 다시 세어 보니 **진짜인 것은 하나뿐**이었습니다:

    투표가 시작됐다        → 시작했다고 못 고치는 것이 아닙니다.
                          18일 동안 그대로 두는 쪽이 더 나쁩니다
    화면 8장을 바꾼다      → 검사와 폭별 캡처로 막을 수 있습니다
    **검사를 못 믿는다**   → **이것만 진짜입니다.** 그리고 순서로 풉니다

## 1. 먼저 — 되돌아올 자리를 박습니다

무엇을 하든 **지금 상태로 한 줄에 돌아올 수 있어야** 오늘 다 할 수 있습니다.

    프로덕션 `c2e2de209` 에 태그를 박습니다
      예: `vote-start-2026-09-20`
    ⚠ 이 커밋은 **정부 조회가 살아 있고 문구가 정직한** 상태입니다.
      무슨 일이 나도 여기로 돌아옵니다

⚠ 태그를 새로 만드는 것은 히스토리 rewrite 가 아니므로 §6 의 총괄 확인
  대상이 아닙니다. **판단으로 하십시오.** 그리고 **지우지 마십시오.**

    ① 리팩터 에이전트   검사 7개를 초록으로 만든다. **아직 커밋 안 함**

       (둘이 다른 파일을 만지는 동안은 병행 가능)

    ③ 리팩터 초록 되면  P4 위에 커밋 → **리팩터만 배포** → 확인
       8화면 × 1440/1280/1024/768/390/320/다크 — **폭마다 가로 넘침 단정**

배포 한 번이 86초였으니 세 번도 5분입니다. **원인을 가릴 수 있는 값이
그보다 큽니다.**

⚠ 각 단계에서 **문제가 보이면 그 단계만 되돌립니다.** 태그가 있으니 최악의
  경우도 한 줄입니다.

## 3. UI 미완 셋 — 오늘 합니다

### ① 그림자 — 카드 78개 중 0개

`--shadow-1` 이 시안 §16 값 그대로 `tokens.css:88` 에 있는데 **쓰는 곳이
0** 입니다. 시안 §21 이 "MVP 느낌의 단순 border 카드" 를 Before 로 꼽았고,
우리가 정확히 그 Before 입니다.

    카드 규칙에 `box-shadow: var(--shadow-1)` 을 붙인다
    ⚠⚠ **다크 재정의가 없습니다** (`--shadow-2` 는 있고 `--shadow-1` 은 없음).
      다크에서 `rgba(30,25,50,.04)` 는 안 보입니다. 두 갈래 중 골라
      **고른 이유를 주석에 적으십시오**:
        (가) 다크는 그림자 대신 표면을 한 단계 밝힌다 (`none` + 배경 한 칸 위)
        (나) 다크용 그림자를 따로 준다 (`--shadow-2` 가 한 것과 같은 모양)
    ⚠ 검사를 붙이되 **쓰는 곳이 N개 이상**임을 단정합니다. 0개를 보고
      통과하면 같은 일이 또 납니다

### ② 섹션 간격 40 → 48

    app.css  section+section{margin-top:var(--s10)}   /* 40px */
          →  var(--s12)                               /* 48px · 시안 §14 */

`--s12` 는 이미 있습니다. 한 줄입니다.
⚠ 8장 전부에 걸리므로 **고친 뒤 8장을 같은 폭에서 다시 찍고 높이를 적습니다.**

### ③ 카드 모서리 — **소유자를 시안으로 정합니다**

문서 둘이 갈려 있습니다:

    design/안심_소싱_돋보기_디자인_MD.md §15   Card **14px**
    design/README.md:72                      카드 16(`--r-xl`)

**시안 문서를 소유자로 합니다.** 시피님이 준 기준이고, README 의 16 은
우리가 나중에 적은 값입니다. 그리고 **실측 최빈값이 이미 14px(36개)** 라
시안과 일치합니다.

    README:72 에 "모서리 값의 소유자는 시안 문서다" 한 줄을 넣어 갈림을 없앤다
    카드를 14 로 통일한다
    ⚠ **12px 29개를 함부로 14 로 올리지 마십시오.** 칩·작은 요소일 수
      있습니다. **무엇이 「카드」인지 먼저 세어 보이고**, 바뀌는 화면을
      캡처로 보인 뒤 통일합니다
