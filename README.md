# 안심 소싱 돋보기

소싱하려는 상품에 KC 인증·리콜·유해물질 문제가 없는지 정부 자료로 확인해 주는 웹 도구입니다.

바로 써 보기 → <https://sourcing-guard.fly.dev>

로그인도 설치도 없습니다. 상세페이지 내용을 복사해 붙여넣으면 결과가 나옵니다.

---

## 누구에게 필요한가

도매 사이트에서 상품을 골라 오픈마켓에 올리는 셀러입니다.

상품을 하나 올리기 전에 원래 확인해야 하는 것이 셋 있습니다.

- 상세페이지에 적힌 KC 인증번호가 실제로 있는 번호인지
- 이 상품이 이미 리콜된 모델은 아닌지
- 이 품목에 어떤 유해물질 기준이 걸리는지

정부 사이트 세 곳을 직접 검색하면 상품 하나에 3~5분이 걸립니다. 하루에 수십, 수백 개를 올리는 셀러는 할 수가 없습니다. 그래서 만들었습니다.

### 안 보고 넘어가면 무슨 일이 생기나

국가기술표준원은 온라인에서 파는 제품을 직접 사서 국내 안전기준으로 시험합니다. 2026년 5월 14일 발표를 보면 구매대행 제품 420개 중 85개가 기준에 못 미쳤습니다. 다섯 개 중 하나꼴입니다.

부적합으로 공표되면 판매 중지 통보, 제품안전정보센터 공개, 고발·과태료가 그 상품을 올린 사람에게 옵니다. 사입한 뒤에 알면 늦습니다.

## 써 보기

### 30초면 됩니다

첫 화면에 예시 버튼 세 개가 있습니다. 누르면 입력이 채워지고 바로 검사됩니다. 전부 실제로 팔리는 상품과 실제 정부 데이터입니다.

| 버튼 | 상품 | 무엇이 보이나 |
|---|---|---|
| 정상 | 도매꾹 슬라임 | 인증번호가 조회되고 리콜 목록에도 없습니다 |
| 주의 | 같은 슬라임에 "재질 PVC" 한 줄 추가 | 번호는 그대로인데 신호가 바뀝니다. 우리가 번호만 보는 게 아니라 페이지를 읽는다는 뜻입니다 |
| 위험 | 모형완구 기차놀이 | 인증은 "적합"인데 2026년 7월 23일에 리콜된 모델입니다 |

세 번째가 이 도구의 이유입니다. 인증번호만 조회하는 방법으로는 이 상품이 통과합니다. 인증이 살아 있는 것과 안전한 것은 다릅니다.

### 화면 네 개

| 화면 | 하는 일 |
|---|---|
| 소개 | 무엇을 보고 무엇을 안 보는지, 예시 세 개 |
| 상품 검사 | 상세페이지를 붙여넣고 한 건을 자세히 봅니다. 표가 이미지뿐이면 화면을 캡처해 Ctrl+V 로 붙여도 읽습니다 |
| 대량 검사 | 엑셀에서 상품명 열을 복사해 붙이면 수백 줄을 한 번에 거릅니다. 결과는 엑셀로 붙여넣을 수 있게 복사됩니다 |
| 감시 목록 | 검사한 상품을 넣어 두면 매일 자동으로 새 리콜 공표와 대조해, 나중에 리콜로 공표될 때 알려 줍니다 |

대량 검사는 상품명만 봅니다. 재질·연령·인증번호는 상세페이지에 있으니, 여기서 걸러낸 것을 상품 검사로 한 번 더 보는 순서입니다.

### 결과 읽는 법

신호는 네 가지입니다.

| 신호 | 뜻 |
|---|---|
| 정상 | 인증번호가 조회되고, 공표된 리콜 목록에 없습니다 |
| 주의 | 확인할 것이 있습니다. 위법이라는 뜻이 아닙니다 |
| 위험 | 인증이 취소·정지됐거나, 리콜 목록과 일치합니다 |
| 일부 확인 | 판단할 근거가 부족합니다 |

모든 줄에 정부 원문 링크가 붙습니다. 저희가 "위험합니다"라고 말하는 대신, 어디에 그렇게 적혀 있는지를 보여 드립니다. 링크를 눌러 직접 확인하실 수 있습니다.

## 확인해 드리는 것과 못 하는 것

가장 중요한 부분입니다. 초록불은 "단속에 안 걸린다"는 보증이 아닙니다. 저희는 상세페이지에 적힌 글을 읽고, 단속은 실물을 수거해 시험합니다. 이 차이는 메울 수 없습니다.

| 항목 | 확인 | 이유 |
|---|---|---|
| 인증번호가 정부 DB 에 있는지 | 가능 | 공개 API 조회 |
| 이미 공표된 리콜인지 | 가능 | 리콜 목록 대조 |
| 이 품목이 인증 대상인지 | 가능 | 세부품목 등급표 596건 조회 |
| 이 품목에 걸리는 유해물질 기준 | 가능 | 고시 원문을 사람이 검수해 만든 규칙 |
| 인증번호를 베껴 적은 것인지 | 불가 | 번호가 실재해도 이 상품 것인지는 글로 알 수 없습니다 |
| 실제 유해물질 함유량 | 불가 | 시험성적서가 있어야 압니다 |
| 앞으로 생길 리콜 | 불가 | 대신 감시 목록에 넣어 두면 공표될 때 알려 드립니다 |
| 충격·인장 같은 성능 시험 통과 여부 | 불가 | 실물이 있어야 합니다. 어떤 시험을 받아야 하는지는 알려 드립니다 |
| 상표권·원산지·수입요건 | 불가 | 이번 버전 범위 밖입니다 |
| 화장품·식품 등 식약처 소관 | 불가 | 별도 신고 체계입니다. 소관이 어디로 보이는지만 알려 드립니다 |

인증번호가 조회되지 않는다고 해서 위반은 아닙니다. 위해도가 낮은 품목은 제조·수입자가 스스로 시험해 확인하므로 조회 DB 에 번호가 없는 것이 정상입니다. 그래서 저희는 그런 경우를 빨간불이 아니라 "확인 필요"로 둡니다.

## 정직하게 적는 숫자

화면에 보이는 숫자는 전부 실제로 잰 값입니다. 보기 좋은 쪽으로 고르지 않았습니다.

| 숫자 | 뜻 |
|---|---|
| 약 37,000건 | 대조하는 리콜 공표 건수 (국내·국외 합계). 화면에 실제 건수와 기준일이 뜹니다 |
| 596건 | 인증 등급을 담은 세부품목 표 (전기·생활용품 561 + 어린이제품 35) |
| 77.0% | 실제 도매 상품 135건에 상품명만 넣었을 때 품목을 맞힌 비율 (104건). 135건에 붙은 답을 한 줄도 남기지 않고 사람이 확인했습니다 |
| 0건 | 안전관리 대상이 아닌 상품 53건에 등급을 잘못 붙인 수 |

마지막 줄이 앞의 셋보다 중요합니다. 모든 상품에 등급을 붙이면 정답률은 올라가지만, 셀러에게 없는 의무를 만들게 됩니다. 모르는 것은 모른다고 두는 쪽을 택했습니다.

## AI 는 어디에 쓰나

AI 는 상세페이지를 읽는 데만 씁니다. 도매 상세페이지는 형식이 제각각이라 (재질이 본문에 섞여 있거나, 표가 이미지뿐이거나, 중국어로 적혀 있거나) 규칙만으로는 읽어낼 수 없습니다. 여기서 상품명·모델명·재질·인증번호·대상연령을 뽑아냅니다.

정상·주의·위험을 정하는 것은 AI 가 아닙니다. 정부 데이터 조회 결과와 사람이 검수한 규칙으로 계산합니다. 같은 상품을 두 번 넣으면 항상 같은 결과가 나오고, 왜 그 신호가 나왔는지 근거를 되짚을 수 있습니다.

## 개발자용

Python 3.11 이상이 필요합니다.

```bash
python -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env          # MOCK_MODE=true 라 키 없이 돕니다
pytest -q                     # 1595 passed (2026-09-14)
uvicorn sourcing_guard.main:app --reload
curl -s localhost:8000/healthz
```

`/healthz` 가 빌드 해시, 리콜 동기화 상태와 건수, 추출기 설정, 감시 스윕 기록을 돌려줍니다.

### 구조

```
상세페이지 붙여넣기
  → extractor.py   AI 추출 (상품명·재질·인증번호 …)
  → verifier.py    정부 API 조회 + 규칙 DB 대조 → 근거 목록
  → scorer.py      신호 계산 (순수 함수, 같은 입력이면 같은 출력)
  → 결과 화면
```

| 파일 | 역할 |
|---|---|
| `models.py` | 스키마. 근거 URL 없는 결과는 생성 자체가 막힙니다 |
| `extractor.py` | AI 추출. 키가 없으면 규칙 기반으로 대체 구동 |
| `kats_client.py` | 국가기술표준원 API 어댑터 |
| `verifier.py` | 조회·대조 오케스트레이션 |
| `scorer.py` | 신호 계산. I/O·난수·현재시각 참조 없음 |
| `item_grades.py` | 세부품목 등급표 조회와 매칭 |
| `watchlist.py`, `storage.py` | 감시 목록 매칭과 저장 |
| `main.py` | FastAPI. 화면 넷과 `/api/v1/*`. 감시 목록 자동 스윕(매일)도 여기서 돈다 — `GET /api/v1/watch` 는 `{items, sweep, alerts}` 를 돌려준다 |
| `data/hazard_rules.yaml` | 유해물질 규칙 DB. `status: draft` 는 계산에서 제외 |
| `design/` | 디자인 정본 (토큰·마스코트·화면 참조) |
