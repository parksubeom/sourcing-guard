# [V] 별칭 조회를 원본 텍스트로도 — 측정만 (2026-09-07)

**넣지 않았습니다.** 시피님이 결정할 자료입니다.

## 무엇을 쟀나

지금은 별칭 조회가 **LLM 이 정리한 상품명**만 본다. 표지어 게이트
(`초등`·`EVA`·`물놀이`)만 원본을 함께 본다 ([Q]). [V] 는 **별칭 매칭 자체**도
원본을 보게 하면 어떻게 되는지다.

⚠ 첫 측정은 틀렸다. `lookup_all` 의 첫 인자를 원본으로 바꿨는데, 그러면
  포함·접두 경로의 본체 검사(`names_the_subject`)까지 원본을 본다 - [Q] 가
  명시적으로 금지한 자리다(09-04 경쟁 양보 버그). 별칭으로 걸린 후보만
  골라 담는 방식으로 다시 쟀다.

### 부작용 — 확정 1건이 갈림으로 후퇴

```
대용량 12리터 전기오븐 제과 제빵 …
  전  ['전기오븐기기']                                    확정
  후  ['전기거치식그릴', '전기오븐기기', '전기휴대형그릴']   갈림 → 확인 요청 화면
```

원본에 '그릴' 이 있어 별칭이 셋을 물었다. 등급은 셋 다 안전확인이라 셀러
의무는 같지만, **화면이 확정에서 확인 요청으로 내려간다.**

## 145 오답을 없앨 수 있나 — 두 길 다 막혔다

- **'물놀이' → '물놀이튜브' 로 좁히기**: [V] 이득이 통째로 사라진다
  (107 → 104). 그 별칭이 원래 137·139 를 잡고 있었고, 좁히면 원본에
  '물놀이튜브' 가 붙어 있지 않아 잃는다.
- **'수건'·'타월' 별칭을 넣어 경쟁으로 양보시키기**: 안전기준준수 부속서 1
  '기타 제품류' 열거는 "가방, 쿠션류, 방석류, 모기장, 커튼, 수의, 덮개 등"
  이고 **수건이 없다.** 다른 제품류에 있을 수 있지만 원문을 아직 못 봤다 -
  확인 전에 넣지 않는다 (R5).

## 정리

이득 **+3 정답(2.3%p)**, 비용 **+1 오답 · 확정 1건 후퇴**. 비대상 오부착은
0 그대로다.

⚠ 안전기준준수 부속서 1 의 제품류 전체 목록을 받아 오면 셈이 달라진다 -
  수건이 어느 제품류인지 확인되면 145 를 그 품목으로 보내고 경쟁에서
  튜브를 양보시킬 수 있다. 그러면 [V] 는 순수 +3 이 된다.
