부속서는 품목별 심화 기준(예: 유아용 섬유제품의 폼알데하이드 20 mg/kg — 공통

## 검수 방법

1. 아래 표의 값을 원문 PDF 해당 페이지와 **한 줄씩** 대조
2. 맞으면 `hazard_rules.yaml` 에서 해당 룰의
   `status: draft` → `status: verified`,
   `verified_by: null` → `verified_by: "이름"`,
   `verified_at: null` → `verified_at: "2026-09-0X"`
3. 틀리면 **승격하지 말고** 값을 고친 뒤 다시 대조

> draft 는 스코어링에서 제외되므로 승격 전까지는 사용자에게 아무 숫자도
> 보이지 않습니다. 서두르지 마세요. 기준치 하나가 틀리면 셀러에게 틀린
> 숫자를 보여주게 되고, 그것이 이 서비스에서 가장 비싼 오류입니다.

**품목군 커버는 verified 룰이 최소 1건 있어야 성립합니다.** 지금은 17건 전부
draft 라 완구·학용품·아동섬유 모두 UNKNOWN 이 나옵니다(의도된 동작).

## ⚠ 검수 중 결정이 필요한 사항 3건

### 1. "납 300 mg/kg" — 해결됨

초기 기획안이 **"납 300 mg/kg"** 을 반복해서 적고 있었으나, 이 고시의 납 기준은
**용출 90**, **함유량 100**(페인트·표면코팅 90)입니다. 300 은 원문 어디에도 없습니다.

출처를 확인한 결과 **완구 부속서의 옛 기준치**였습니다. 부속서 개정으로
300 → 100 이 되어 공통안전기준과 통일됐습니다. 즉 폐지된 값입니다.

→ 기획서 §2.3·§4②·§7 과 핸드오프 §4 를 수정했습니다. 제출 서류에 남아 있었다면
발표에서 틀린 숫자를 공개할 뻔했습니다. 오래된 자료에 300 이 보이면 옛 값입니다.

`tests/test_docs.py` 가 제출용 기획서에 이 값이 다시 들어오는 것을 막습니다.

### 2. 프탈레이트 적용범위 — 부분 해결

"DnOP·DINP·DIDP 는 입에 넣도록 의도된 완구에 한정" 은 **완구 부속서의 옛 조항**이며
개정으로 삭제됐습니다. 지금은 재질(합성수지제) 기준으로만 적용됩니다.

물질 수는 해결됐습니다. 현행 제2022-220호 p.3 표에서 **DIBP(CAS 84-69-5)를
원문 확인**해 7종으로 승격했습니다 (2026-09-01).
`KC-COMMON-3.1.3-PHT` 의 `substances_pending` 에 분리해 뒀으니, 원문에서 확인되면
`substances_covered` 로 옮기세요. 옮기기 전에는 총합 계산에 들어가지 않습니다.

### 3. 섬유 관련 룰의 `applies_to`

폼알데하이드·아릴아민·pH 를 `children_textile` 로만 두었습니다. 그런데 공통기준은
모든 어린이제품에 적용되고 비고는 "섬유제품" 으로 좁힙니다.
**섬유 부분이 있는 완구**(예: 인형 옷)에 걸리는지가 애매합니다.

→ 넓게 잡으면 오탐이 늘고, 좁게 잡으면 놓칩니다. 스캔은 R3(모르면 UNKNOWN)이
적용되는 영역이라 좁게 두었으나, 검수자가 판단해 주세요.
