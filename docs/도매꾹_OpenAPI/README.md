## 곁들여 확인된 것 — SafetyKorea 키

`~/Downloads/OpenAPI_사용신청서.pdf` 는 **도매꾹이 아니라 국가기술표준원
제품안전정보센터** Open API 신청서다. 도매꾹 키와 무관하지만 한 문장이 우리에게
걸린다:

> 4) 발급받으신 인증키는 타인/타기관에 양도가 불가능하며 이를 어길 시 별도의 통보
>    없이 인증이 취소될 수 있습니다.

즉 **B2B 납품 시 고객사가 자기 키를 받아야 한다.** 우리 키를 넘겨 쓸 수 없다.
같은 신청서에 우리가 적어 낸 이용목적도 남아 있다 - "이커머스 판매자용 제품
안전인증·리콜 정보 조회 서비스 개발 … 모든 조회 결과에 제품안전정보센터 원문
링크를 병기함. (원티드 AI 챔피언십 2026 출품 시제품, 비영리)". 이용기간
2026-09-01 ~ 2027-08-31.

⚠ 도매꾹 키의 **계정 종속 여부는 여전히 미확인**이다. 이 PDF 로는 알 수 없고,
  발급 화면 문구가 필요하다 (참조.md §7).
