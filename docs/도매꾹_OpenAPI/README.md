원문 4편은 2026-09-08 에 들어왔다. 로그인 상태에서 저장한 페이지이고, 확인해 보니
API 키·개인정보는 들어 있지 않다 — 들어 있는 연락처는 도매꾹 자신의 것
(`techsupport@ggook.com`, 사업자번호 1건)과 문서 예시값(`000-00-00000`)뿐이다.

⚠ **원문과 참조.md 가 어긋나는 곳이 있다. 그때는 실호출을 따른다.**
  참조.md §7 이 어긋난 곳을 표로 적어 뒀다 — 최상위 `domeggook` 껍데기 · 문서가
  int 라 한 필드가 실제로는 문자열 · `detail.safetyCert` 는 `null` 일 수 있고 실호출에서
  **배열**이었다 · `infoDuty.item[].name` 은 고시 문구 그대로다.

⚠ **호출 한도·IP 등록·키 종류는 이 4편에 없다.** 원문을 받아 다시 확인했다 —
  '분당' · '15,000' · 'IP' 문자열이 4편 어디에도 없다. 그 내용은 별도 문서인
  「OPEN API 이용 방법」(<https://openapi.domeggook.com/main/guide/start>)에 있고
  참조.md §1 이 그쪽을 출처로 적고 있다. 즉 작업로그 2026-09-04 의 "이 문서에 없다"
  는 **맞는 기록이다** — 본 것이 상품상세정보 문서였다.

⚠ **요약문을 새로 쓰지 않는다.** 참조.md 가 정본이다. 같은 내용을 두 곳에 두면
  갈라진다 - 이 저장소의 반복 결함이 문서가 코드보다·다른 문서보다 앞서 나가는
  것이다.

## 곁들여 확인된 것 — SafetyKorea 키

`~/Downloads/OpenAPI_사용신청서.pdf` 는 **도매꾹이 아니라 국가기술표준원
제품안전정보센터** Open API 신청서다. 도매꾹 키와 무관하지만 한 문장이 우리에게
걸린다:

> 4) 발급받으신 인증키는 타인/타기관에 양도가 불가능하며 이를 어길 시 별도의 통보
>    없이 인증이 취소될 수 있습니다.

즉 **B2B 납품 시 고객사가 자기 키를 받아야 한다.** 우리 키를 넘겨 쓸 수 없다.
같은 신청서에 우리가 적어 낸 이용목적도 남아 있다 - "이커머스 판매자용 제품
안전인증·리콜 정보 조회 서비스 개발 … 모든 조회 결과에 제품안전정보센터 원문
링크를 병기함. (원티드 AI 챔피언십 2026 출품 시제품, 비영리)". 이용기간
2026-09-01 ~ 2027-08-31.

⚠ 도매꾹 키의 **계정 종속 여부는 여전히 미확인**이다. 이 PDF 로는 알 수 없고,
  발급 화면 문구가 필요하다 (참조.md §7).
