상품리스트

주어진 조건에 맞는 판매중 상품 목록을 반환하는 API입니다

API 정보

주어진 조건에 맞는 판매중 상품 목록을 반환하는 API입니다.

응답 결과는 동일한 검색조건으로 도매꾹·도매매 웹에서 조회한 상품 목록과 동일하며,

판매중지·판매종료·품절·단종 상품은 포함되지 않습니다.

상품리스트_4.1 ver (권장)

권장 ver: 4.1

Mode: getItemList

Method: GET

Endpoint: https://www.domeggook.com/ssl/api/

Request Example:

https://www.domeggook.com/ssl/api/?ver=4.1&mode=getItemList&aid={API_KEY}&market=dome&om=json&kw=마스크&sz=50&pg=1&so=rd

상품목록 검색을 위하여 아래 검색 조건 중 하나 이상의 파라미터 설정이 필요합니다.

  • 기획전번호 (ev), 카테고리 (ca), 아이디(id), 검색어(kw), 상품번호(itemNo))

Request

순서

항목( 자료형, 필수여부)

설명

1

ver (string,Y) 

API Version

2

mode (string,Y) 

API 호출 모드값 : getItemList

3

aid (string,Y) 

API Key

4

market (string,Y) 

서비스 코드

· dome : 도매꾹

· supply : 도매매

5

om (string,Y) 

출력 형식 : json | xml

6

sz (int,N) 

페이지당 상품 출력개수

· 1 이상 200 이하의 정수를 입력

· 미입력시 20이 기본값

7

pg (int,N) 

페이지 번호

8

so (string,N) 

검색결과 정렬방식

· se : 정확도순 (검색어 사용시 외에는 사용불가 / 검색어 사용시 기본값)

· rd : 도매꾹랭킹순 (검색어 미사용시 기본값)

· ha : 인기상품순

· aa : 낮은가격순

· ad : 높은가격순

· sd : 신규판매자순

· qa : 적은판매단위순

· qd : 많은판매단위순

· da : 최근등록순(상품정보등록/수정일 최근순)

9

ev (int,N) 

기획전 번호

· 특정 기획전에 속한 상품을 검색할 때에만 입력

· market값이 "dome"일 때에만 적용됨

10

ca (string,N) 

카테고리 검색

· 2자리의 숫자쌍 5개가 언더 바(_)로 연결된 형태로 입력

　ex) 01_01_00_00_00

· 미입력시, 모든 카테고리의 상품을 검색

· 카테고리 값이 잘못 입력된 경우, 미입력한 것으로 간주함

· 대분류만으로 검색할 수 없으며, 중분류 이하로 검색 가능함

ex) 01_00_00_00_00 검색 불가 , 01_11_00_00_00 검색 가능

11

id (string,N) 

판매자 아이디 검색

12

nick (string,N) 

판매자 닉네임 검색

13

kw (string,N) 

검색어 검색

14

mnp (int,N) 

가격대 검색 / 최저가격대

15

mxp (int,N) 

가격대 검색 / 최고가격대

※ mnp에 입력된 값보다 작은 값을 입력한 경우, mxp 값은 미입력한 것으로 간주함

16

mnq (int,N) 

최소구매수량 검색 / 최저수량

17

mxq (int,N) 

최소구매수량 검색 / 최대수량

※ mnq에 입력된 값보다 작은 값을 입력한 경우, mxq 값은 미입력한 것으로 간주함

18

who (string,N) 

배송비 부담

· S : 무료배송 상품만 검색

· B : 착불 상품만 검색

· P : 배송비 선결제 상품만 검색

· C : 선결제/착불 선택가능 상품만 검색

19

org (string,N) 

국산 여부

· kr : 국내산 상품만 검색

· fr : 국외산 상품만 검색

· 이 외의 값이 입력된 경우, 미입력한 것으로 간주함

20

sgd (boolean,N) 

우수판매자 상품 검색

· true : 우수판매자 상품만 검색

· false : 전체상품 검색 (기본값)

21

fdl (boolean,N) 

빠른배송 상품 검색

· true : 빠른배송 상품만 검색

· false : 전체상품 검색 (기본값)

22

lwp (boolean,N) 

최저가확인상품

· true : 최저가확인상품만 검색

· false : 전체상품 검색 (기본값)

23

dfos (boolean,N) 

해외직배송 상품 검색

· true : 해외직배송 상품만 검색

· false : 해외직배송 제외 상품 검색

· null : 전체상품 검색 (기본값)

24
