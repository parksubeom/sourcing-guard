API 정보

상품번호(no)를 기준으로 도매꾹·도매매의 특정 상품 1개에 대한 상세 정보를 조회하는 API입니다.

상품상세정보_4.6(권장)

권장ver: 4.6

Mode: getItemView

Method: GET

Endpoint: https://www.domeggook.com/ssl/api/

Request Example:

https://www.domeggook.com/ssl/api/?ver=4.6&mode=getItemView&aid=#{api key}&market=dome&om=json&no=#{item_no}
