# 도매꾹 Open API 참조 — 안심 소싱 돋보기용

정리 2026-09-08 · 출처: 도매꾹 Open API 공식 문서 4편(상품리스트 4.1 · 상품상세정보 4.6 ·
카테고리 목록 1.0 · 카테고리 정보 2.0). 원문 HTML 은 같은 디렉터리의 `원문_*.html` 이다.
이 문서는 **우리가 쓰는 부분만** 옮긴 것이고, 필드명·값은 원문 그대로다.

## ⚠ 2026-09-08 실호출로 정정 — 문서와 어긋나는 곳은 **실호출을 따른다**

    최상위 domeggook 껍데기       header · list · item 전부 `domeggook` 아래에 있다
    문자열 자료형                 문서가 int 라 한 필드가 실제로는 "58491071" 문자열
    detail.safetyCert null 가능   필드 자체가 없을 수 있고, 있을 때는 **배열**이었다
    infoDuty name 은 고시 문구 그대로   "KC인증 필 유무" 가 아니라 긴 고시 문장

§7 이 곳마다 문서값과 실제값을 표로 적었다. 여기(§1~6)는 원문을 옮긴 것이므로 §7 과
어긋나면 **§7 이 맞다** — 실호출이 정본이다.

⚠ 이 문서에 적힌 것만 사실이다. "아마 이럴 것" 은 §7 에 미확인으로 따로 모았다 (R5).

## 1. 공통

| 항목 | 값 |
|---|---|
| Endpoint | `https://www.domeggook.com/ssl/api/` (GET) |
| 인증 | 쿼리 `aid={API_KEY}` |
| 출력 형식 | `om=json` 또는 `om=xml` |
| 호출 한도 | **분당 180회 · 하루 15,000회.** 초과 시 자동 차단, HTTP **429** (출처: openapi.domeggook.com/main/guide/start) |
| IP | 키 발급 시 호출 IP 를 등록한다. 등록되지 않은 IP 에서의 호출은 거부된다 → 401/403 이 나면 IP 변경부터 의심 |
| 존재하지 않는 상품 | **40번 오류** (상품상세정보 문서) |
| 발급 범위 | 이 키는 **Open API(상품·카테고리 조회)** 다. 상품등록·구매·판매 API 는 Private API 로 별도 신청 — 우리는 필요 없다 |

CLAUDE.md R4: 허용 호스트는 `www.domeggook.com/ssl/api/` 하나. HTML 스크래핑 금지.
배포본에서 호출하려면 나가는 IP 가 고정이어야 한다 — 확정 전까지 로컬 수집 스크립트에서만 호출.

## 2. 상품리스트 `getItemList` (ver 4.1, 권장)

판매중 상품 목록. **판매중지·판매종료·품절·단종 상품은 결과에 포함되지 않는다.**
검색 조건(`ev` `ca` `id` `kw` `itemNo`) 중 하나 이상 필수.

### 요청 예
```
https://www.domeggook.com/ssl/api/?ver=4.1&mode=getItemList&aid={API_KEY}&market=dome&om=json&kw=마스크&sz=50&pg=1&so=rd
```

### 요청 파라미터 (우리가 쓰는 것)

| 파라미터 | 필수 | 설명 |
|---|---|---|
| `ver` | Y | `4.1` |
| `mode` | Y | `getItemList` |
| `aid` | Y | API Key |
| `market` | Y | `dome` 도매꾹 · `supply` 도매매 |
| `om` | Y | `json` / `xml` |
| `kw` | N | 검색어 |
| `itemNo` | N | 상품번호로 검색 |
| `sz` | N | 페이지당 건수, **1~200**, 기본 20 |
| `pg` | N | 페이지 번호 |
| `so` | N | 정렬. `se` 정확도순(검색어 사용 시 기본) · `rd` 도매꾹랭킹순 · `da` 최근등록순 등 |
| `ca` | N | 카테고리 코드 `00_00_00_00_00`. 중분류 이하만 검색 가능 |
| `org` | N | `kr` 국내산 · `fr` 국외산 |

그 외(가격대 `mnp`/`mxp`, 수량 `mnq`/`mxq`, 배송 `who`, `sgd` `fdl` `lwp` `dfos`, `id` `nick` `ev`)는 원문 참조.

### 응답

⚠ **경로에 `domeggook.` 접두어가 빠져 있다.** 자료형도 몇 개 틀렸다 - §7 참조.

| 필드 | 형 | 설명 |
|---|---|---|
| `header.numberOfItems` | int | 전체 상품 수 |
| `header.currentPage` / `itemsPerPage` / `numberOfPages` | int | 페이지네이션 |
| `list.item.no` | int | **상품번호** → `getItemView` 의 `no` |
| `list.item.title` | string | **상품제목** → 표본 상품명과 정확 일치 비교에 쓴다 |
| `list.item.url` | string | 상품 URL |
| `list.item.thumb` | string | 썸네일 URL |
| `list.item.id` / `nick` | string | 판매자 아이디 / 닉네임 |
| `list.item.unitQty` | int | 최소구매수량 |
| `list.item.market.domeggook` / `supply` | boolean | 도매꾹 / 도매매 판매중 여부 |
| `list.item.deli.fromOversea` | boolean | 해외직배송 상품 여부 |
| `list.item.comOnly` / `adultOnly` / `lwp` / `price` / `priceOrg` / `idxCOM` / `deli.*` | | 원문 참조 |

## 3. 상품상세정보 `getItemView` (ver 4.6, 권장)

### 요청 예
```
https://www.domeggook.com/ssl/api/?ver=4.6&mode=getItemView&aid={API_KEY}&om=json&no={item_no}
https://www.domeggook.com/ssl/api/?ver=4.6&mode=getItemView&aid={API_KEY}&om=json&multiple=true&no=111,222,333
```

### 요청 파라미터

| 파라미터 | 필수 | 설명 |
|---|---|---|
| `ver` | Y | `4.6` |
| `mode` | Y | `getItemView` |
| `aid` | Y | API Key |
| `no` | Y | 상품번호. `multiple=true` 면 콤마로 연결, **최대 100개** |
| `om` | Y | `json` / `xml` |
| `multiple` | N | `true` 다중 / `false` 단일(기본) |

| `allItem` `sellerId` `sId` | N | 공급사 본인 상품 조회용. 우리는 쓰지 않는다 |

### 응답 — 우리가 쓰는 필드

⚠ **실제 경로는 `domeggook.item[]` 이다.** `safetyCert` 는 없을 수 있고, 있으면 **배열**이다 - §7 참조.

| `basis.title` | string | **상품명** |
| `basis.keywords.kw` | string[] | 상품 키워드 개별 단어 |
| `basis.dateReg` / `dateStart` / `dateEnd` | date | 등록일 / 판매 시작·종료일 |

**상품 관련 정보 `detail`**

| 필드 | 형 | 설명 |
|---|---|---|
| `detail.size` | string | 상품크기(치수/용량) |
| `detail.weight` | string | 상품무게 |
| `detail.country` | string | **원산지** |
| `detail.manufacturer` | string | **제조사** |

**안전인증 `detail.safetyCert`** — 공급사가 입력한 값. 사실이 아니라 **입력**이다.

| 필드 | 형 | 설명 |
|---|---|---|
| `exem` | `Y`/`N` | KC 인증 **면제** 정보 사용 여부. `N` 이면 아래 exem* 항목 없음 |
| `exemTitle` | string | 면제 대상 타이틀 — `구매대행` 또는 `병행수입`. 값 없으면 `-` |

| ~~`type`~~ ~~`name`~~ | | **폐기 예정. 쓰지 않는다.** `certType` / `certName` 을 쓴다 |

**상품정보제공고시 `detail.infoDuty`** — 「전자상거래 등에서의 상품정보제공 고시」(공정위 고시 제2012-49호) 의무고시.

| 필드 | 형 | 설명 |
|---|---|---|
| `infoDuty.type` | string | **품목명 — 공정위 고시의 품목분류** (예: `가공식품`, 의류, 가구 …) |
| `infoDuty.item[]` | array | 고시 항목 목록 |
| `infoDuty.item[].type` | string | `item` 품목별 재화 정보 · `transaction` 거래조건(모든 품목 공통) |
| `infoDuty.item[].name` | string | 고시항목명 (예: 제품소재, KC인증 필 유무, 제조국, 제조자 …) |
| `infoDuty.item[].desc` | string | 고시내용 |

⚠ 원문의 응답 예시 자체가 `desc: "상세정보 별도표기"`, `country: "상세정보별도표기"` 다.

비율을 반드시 센다** — 그 비율이 이 API 가 상세페이지를 대신하는 정도다.

**상품설명 `desc`**

| 필드 | 형 | 설명 |
|---|---|---|
| `desc.contents.item` | string | 상세설명 HTML — 상품정보 부분. **원문 예시는 `<div><img src=…></div>` 한 장이다.** 태그를 벗기면 텍스트가 거의 안 남을 수 있다 |
| `desc.contents.deli` / `event` / `otherItem` | string | 배송·교환·반품 / 이벤트 / 다른 상품 홍보 HTML. 우리는 쓰지 않는다 |
| `desc.notice` | string | 판매자 공지 |
| `desc.comment.memo` / `date` | | 상단 메모(품절·배송지연) |
| `desc.license.usable` / `msg` | | 상세 이미지 타 마켓 사용 허용 여부 |

**카테고리 `category`**

| 필드 | 형 | 설명 |
|---|---|---|
| `category.parents.elem[]` | array | 상위 카테고리 경로. 각 `name` · `code` · `depth`(1 이 최상위) |
| `category.current` | | 현재 카테고리 `name` · `code` · `depth` (원문 표의 자료형 표기가 어긋나 있음 — 실호출로 확인) |

**판매자 `seller`** (필요 시)

`seller.id` · `nick` · `type`(일반과세자/간이과세자/개인판매자/면세사업자) · `global`(해외판매자 여부) ·
`company.name` · `company.cno`(사업자등록번호) · `company.addr` 등. 원문 참조.

**그 외 절** — `price.*` `labeledPrice.*` `qty.*` `deli.*` `channel.*` `thumb.*` `selectOpt` `benefits.*`
`popular.*` `priceCompare.*` `contentsRenewal`: 가격·재고·배송·옵션. 우리 용도 아님. 원문 참조.

## 6. 우리 쪽 매핑 — ProductFacts 로 옮길 때

| ProductFacts | API 필드 | 주의 |

| `product_name` | `basis.title` | |

| `model_name` | `detail.model` | `-` 이면 없음 |
| (원산지) | `detail.country` | |
| (면제 표기) | `safetyCert[].exem=Y` · `exemTitle` | 구매대행·병행수입. R3-b 로 어떻게 표시할지 미결 |

두지 말고 "확인 안 됨" 으로. 못 찾은 것과 찾아보지 않은 것은 다르다.

## 7. 실호출로 확인한 것 — 2026-09-08

`DomeggookClient` 로 실제 호출해 채웠다. 호출 예:

    search("모기장", sz=3)          getItemList ver=4.1
    view([58491071, 35749587])     getItemView ver=4.6 multiple=true

원문 응답은 `/tmp/kid/dome_probe_*.json` (일회성 탐침이라 리포에 두지 않았다).

⚠ **수집본은 원문이 아니라 정제본이다** (`tests/fixtures/도매꾹_정제_*/`).
  도매꾹 응답에는 제3자 사업자·개인정보가 들어오므로 저장 전에
  `domeggook_pii.write_sanitized()` 를 거친다. 무엇을 지웠는지는 그 모듈 머리와
  `<파일명>.정제.json` 사이드카에 있다. `도매꾹_원문_*/` 은 더 만들지 않는다.

### ⚠ 문서(§1~6)와 실제가 다른 곳 — **실제를 따른다**

| 곳 | 문서 | 실제 |
|---|---|---|
| **최상위** | `header` · `list` · `basis` … | **전부 `domeggook` 으로 감싸여 있다** — `domeggook.header`, `domeggook.list.item`, `domeggook.item[]` |
| `list.item.no` | int | **string** (`"58491071"`) |
| `list.item.unitQty` | int | **string** (`"4"`) |
| `list.item.market.*` | boolean | **string** (`"true"` / `"false"`) |
| `header.itemsPerPage` | int | **string** (`"3"`) |
| `detail.safetyCert` | `cert` `Y`/`N` 등 객체 | **없을 수 있고, 있으면 배열이다** — 공급사가 안 넣으면 키 자체가 없다. 수집 100건 중 **20건만** 갖고 있었고 그 20건은 전부 `[{...}]` 배열이었다 |

즉 값 하나를 꺼낼 때마다 `int(...)` · `== True` 를 가정하면 깨진다. 어댑터는
**원문 dict 를 그대로 돌려주고**(가공 안 함) 꺼내는 쪽에서 자료형을 맞춘다.

### 채워진 항목

**`multiple=true` 응답 최상위 모양** — 객체 안에 배열이다.

    {"domeggook": {"etc": {...}, "item": [ {상품1}, {상품2} ]}}

`etc` 는 `showByMailzine` · `connectStompApi` · `denyMarket` (전부 `"false"`
문자열). 우리 용도 없다. 상품 하나만 조회해도(`multiple=false`) 모양이 같은지는
A-3 수집에서 확인한다 — 우리는 항상 `multiple=true` 로 부른다.

상품 하나의 최상위 키:

    basis · benefits · category · channel · deli · desc · detail ·
    price · qty · return · selectOpt · seller · thumb

**`category.current` 자료형** — 문서 표기와 같다.

    {"name": "차량용햇빛가리개", "code": "12_15_09_16_00", "depth": 4}
    name: str · code: str · depth: **int**

**`infoDuty.item[].name` 실제 표기** — 문서가 예상한 짧은 이름이 아니라
**공정위 고시 문구 그대로**다. 탐침 1건에서 본 것:

    [item]        품명 및 모델명
    [item]        법에 의한 인증·허가 등을 받았음을 확인할 수 있는 경우 그에 대한 사항
    [item]        제조국 또는 원산지
    [item]        제조사
    [item]        A/S 책임자와 전화번호 또는 소비자상담 관련 전화번호
    [transaction] 청약철회 및 계약의 해제에 관한 사항

⚠ "KC인증 필 유무" 가 아니라 **"법에 의한 인증·허가 등을 받았음을 확인할 수
  있는 경우 그에 대한 사항"** 이다. 이름으로 항목을 찾을 때 이 긴 문구를
  써야 한다. `infoDuty.type` 이 품목분류에 따라 달라지므로 항목 이름도
  달라진다 - 235건 분포는 A-3 수집 뒤에 센다.

**"상세정보 별도표기" 류 변형** — 탐침 1건에서 이미 둘이 나왔다.

    "상세설명참조"            ← 문서 예시에 없던 표기
    "[상세정보 별도표기]"      ← 대괄호가 붙는다
    "상세설명참조 / 상세설명참조"  ← 두 값을 슬래시로 이은 항목(품명 및 모델명)

⚠ 탐침 1건의 `infoDuty.item` 6개 중 **5개가 이 류**였다. 문서의 응답 예시가
  그런 모양이었던 것이 예외가 아닐 수 있다는 우려가 첫 호출에서 그대로
  확인됐다. 전체 비율은 A-5 에서 센다 - **그 비율이 이 API 가 상세페이지를
  대신하는 정도다.**

    ⚠ `detail.safetyCert` 가 없는 것도 같은 성격이다. 탐침 1건이 그랬고, 수집
      100건에서는 **80건이 없었다**(20건만 있음).

### 아직 미확인 — 실호출로는 알 수 없다

- **키가 계정 종속인지.** 발급 화면 문구가 필요하다. 종속이면 셀러가 자기
  키를 입력해야 하고 UI 가 늘어난다.
- **복수 IP 등록 가능 여부.** 배포본에서 부르려면 고정 egress IP 를 등록해야
  하고, 그때 이 PC 의 IP 를 유지할 수 있는지가 걸린다.

  ⚠ 곁들여 확인된 것: **SafetyKorea** 키는 "타인/타기관에 양도가 불가능" 하다
    (신청서 원문). 도매꾹도 같은 정책이면 B2B 납품 시 고객사가 각자 발급해야
    한다. `docs/도매꾹_OpenAPI/README.md` 참조.

## 8. 수집 스크립트 규칙 (요약 — 자세는 프롬프트 [A-3])

1. 이전 프로세스 확인·종료 → 프로세스 하나 → `python -u`.
2. 호출 간격 0.4초 이상. 429 는 재시도 말고 기록.
3. `getItemList(kw=상품명, sz=50)` → `title` 정규화 후 **정확 일치**만 채택.
   0건·2건 이상은 미확인.
4. 채택 `no` 를 100개씩 `getItemView(multiple=true)`.
5. 응답 원문 JSON 을 그대로 저장(`tests/fixtures/도매꾹_원문_YYYY-MM-DD/`).
6. 키는 `.env` `DOMEGGOOK_API_KEY`. 리포·로그·커밋 메시지에 절대 남기지 않는다.
