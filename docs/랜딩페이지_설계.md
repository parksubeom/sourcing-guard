# 랜딩 페이지 설계 — 안심 소싱 돋보기

작성 2026-09-06 · ④·⑤ 숫자 2026-09-09 갱신 · 제출 9/20 · 투표 9/21~10/5

확정된 것: **`/` 랜딩 · `/scan` 도구로 분리**, 매칭은 **법령 품목명 경로 235건 전수 측정**.

⚠⚠ **캐릭터 "돋이" 전제는 2026-09-11 폐기.** 시피님이 디자인을 새로 한다. SVG 셋
(`mark.svg`·`logo.svg`·`favicon.svg`)은 **오지 않는다.** 아래 §2 히어로의 `[돋이]`
자리와 §5 로고 적용 절은 그 전제 위에 쓴 것이라 **읽되 따르지 않는다.** [G-1] 은
디자인 무관 구조만 만든다 - 로고·색·파비콘 금지, `app.css` 기존 토큰만, 마크 자리는
빈 `<span>`. 임시 로고·임시 색을 만들지 않는다.

## 0. 이 문서가 푸는 문제

청중이 둘이고 원하는 게 반대다.

```

               → 서사가 필요하다. 도구 화면만으로는 전달이 안 된다

               → 스크롤을 시키면 그 30초를 잃는다
```

핸드오프 §9 가 "클릭 한 번에 RED/AMBER/GREEN", "캐시 히트 3초 이내" 를 적어 둔 것이
뒤쪽 제약이다. **분리하되 히어로에서 바로 결과로 갈 수 있게** 해서 둘 다 만족시킨다.

### 데모 버튼은 서버가 단일 출처다

`demos.py` 주석이 이미 경고하고 있다 — 프론트에 문구를 따로 적으면 서버의 면제 목록과
갈라지고, 상한을 넘긴 순간 투표자가 429 를 본다. **랜딩도 `/api/v1/demos` 를 읽어서
버튼을 그린다.** 문구를 landing.html 에 하드코딩하지 않는다.

### 버튼을 누르면

`/scan?demo=<tone>` 으로 이동하고, `/scan` 이 쿼리를 읽어 **자동으로 검사까지 실행**한다.
투표자 클릭 1번에 결과가 뜬다. 결과 위에 "이 예시는 …" 한 줄을 붙여 실제 검사와 구분한다.

⚠ 세 케이스의 힘은 **초록·주의가 같은 슬라임**이고 "PVC 재질" 한 줄 차이라는 데 있다.
버튼 라벨이 그 관계를 말해야 한다. 세 개를 독립된 예시처럼 보이게 하면 장면이 죽는다.

## 3. 스크롤 아래 — 심사위원용

순서가 중요하다. **"안 하는 것" 이 두 번째다.**

### ① 무엇을 하나 — 3칸

```
KC 인증번호 조회    번호가 실재하는지, certState 가 무엇인지
리콜 대조          국내 4,244 · 국외 33,085 건과 대조
유해물질 기준       고시·부속서에서 우리가 만든 규칙 DB
```

각 칸에 **정부 원문 링크가 붙는다**는 것을 명시. 그게 R2 다.

### ② 무엇을 안 하나 — 이 절이 제일 세다

> 합법/불법을 판정하지 않습니다.

- 초록불은 보증이 아니다. 우리는 상세페이지 텍스트를 읽고, 단속은 실물을 수거해 시험한다
- 확인 못 하는 것: 인증번호 도용, 실제 함유량, 미래 리콜, 식약처 소관, 상표권·원산지
- **이건 결함이 아니라 사업 모델의 전제다** — "안 걸립니다" 라고 말하는 순간 사후 리콜
  책임이 우리에게 온다. OMS 가 이 기능을 안 만든 이유가 정확히 그 책임 문제다

기획서 §3.2 를 그대로 옮기면 된다. 심사위원이 "그래서 이게 뭐가 다른가" 를 물을 때
답이 되는 자리다.

### ③ 어떻게 만들었나 — AI 활용의 적절성

예선 심사 기준에 이 항목이 있다. **"AI 판정을 금지한다"는 논리만 내세우면
"그럼 AI 는 왜 쓰나" 에 답을 못 한다.**

```
LLM 이 하는 일    추출 · 분류 · 설명 · 법령 품목명 번역
LLM 이 안 하는 일  판정. 위험도는 scorer.py 의 순수 함수가 단독으로 한다

코드로 강제한 것
  Finding 은 근거 URL 없이 생성 자체가 실패한다
  "안전합니다" 같은 단정 문구는 생성자에서 거부된다
  ProductFacts 는 extra="forbid" — 판정 필드가 몰래 못 들어온다
  규칙 DB 는 draft → 사람 검수 → verified 를 거쳐야 스코어링에 들어간다
```

**법령 품목명 경로를 여기서 보여준다.** 561건 목록에서 고르게 하지 않고 이름만
자연스럽게 답하게 한 뒤 표가 검증한다 — LLM 을 판정기가 아니라 **번역기**로 쓰는 그림.
이게 "적절성" 항목의 답이다.

### ④ 정직한 숫자 — 이력을 그대로 보여준다

(**2026-09-12 갱신** - [결정 1] 로 기준 추출기가 GPT 가 됐다. 숫자는
`scripts/audit_tally.py` 의 `BASELINE[BASELINE_EXTRACTOR]` 이 정본이고
`tests/test_landing.py` 가 대조한다. 여기 적은 값이 그것과 다르면 여기가 틀린 것이다.)

⚠⚠ **71% 와 24% 는 매칭률이고 20.0% 부터가 정답률이다.** 축이 다르다. 라벨 없이
  나란히 놓으면 읽는 사람이 71% 를 정답률로 읽는다 - **09-04 에 우리가 실제로
  한 실수다**(`docs/M_커버리지지도_2026-09-12.md` 머리 주석). 분모도 셋 다 다르다.

⚠ 73.3% 는 **Claude 기준 값**이었다. [결정 1](2026-09-11)로 기준 추출기가 GPT 가
  되면서 70.4% 로 옮겼다. 상한 83.7% 는 둘 다 같다 - 그것이 "추출기를 바꿔도 등급
  결과가 크게 안 흔들린다" 의 증거라 `단건경로_claude_235.json` 을 대조군으로
  남겨 뒀다 (CLAUDE.md R7).

**이 절을 넣는 것이 이 랜딩의 가장 큰 판단이다.** 71 → 24 → 20 으로 내려왔다가
규칙과 검수로 73 까지 올라온 과정을 보여주면, 숫자가 **약점이 아니라 제품 주장의
증거**가 된다. "우리는 모르는 것을 모른다고 말한다" 를 코드가 아니라 숫자로 증명하는 자리다.

두 숫자를 가른 이유를 한 줄로 붙인다 — "추출기를 바꿔 재 보니 검수된 적 없는 쌍이
정답으로 세어지고 있었다. 그래서 사람이 본 쌍만 정답으로 세고, 나머지는 상한으로 따로 적는다."
시피님 판정이 끝나 두 숫자가 하나로 합쳐지면 이 절도 한 숫자로 줄인다.

숫자는 하드코딩하지 말고 기획서와 같은 원자료에서 그린다. `test_docs` 가 기획서를
잠그는 것과 같은 방식으로 랜딩 문구도 잠근다 — 랜딩이 기획서와 다른 숫자를 말하면 검사가 실패한다.

## 4. 지켜야 할 것

- **단정 표현 금지** (CLAUDE.md §9). "안전합니다"·"합법입니다"·"판매 가능합니다" 를
  랜딩 카피에도 쓰지 않는다. 마케팅 문구라고 예외가 아니다
- **화면 중복 검사에 걸린다.** 랜딩과 `/scan` 이 같은 안내문을 쓰면 24자 이상 겹치는
  순간 검사가 실패한다. 히어로 설명문을 `/scan` 에서 지우거나 다르게 쓴다
- **정부 식별 요소를 가져오지 않는다** (app.css 머리주석). KC 마크·정부 로고를
  랜딩에 놓지 않는다. 링크는 되지만 마크는 안 된다
- **접근성**: 데모 버튼은 `<button>` 이고 결과 영역은 `aria-live`. 지금 index.html 이
  이미 그렇게 돼 있으니 같은 수준을 유지한다

## 5. 로고 적용 — ⚠ **2026-09-11 폐기** (돋이 SVG 는 오지 않는다 · 디자인은 시피님이 새로 함)

(아래는 폐기 전 원문. 마크 자리는 빈 `<span>` 으로 둔다.)

첨부 셋을 `sourcing_guard/static/` 에 넣는다.

| 파일 | 쓰는 곳 |
|---|---|
| `mark.svg` | 헤더 32px. **인라인으로 넣어야 한다** — `<img>` 로 부르면 `currentColor` 가 상속되지 않아 검게 나온다. 지금 index.html 의 `.mark` 자리에 그대로 넣으면 된다 |
| `logo.svg` | 랜딩 히어로. 락업(돋이 + 워드마크). 역시 인라인 |
| `favicon.svg` | `<link rel="icon" type="image/svg+xml" href="/static/favicon.svg">`. 색이 박혀 있어 `<img>` 로 써도 된다 |

**지금 헤더의 돋보기+체크 마크는 지운다.** 렌즈 안의 체크는 "확인됐다"는 판정의
기호이고, 초록불이 보증이 아니라고 정해 놓은 것(§3.2)과 어긋난다.

워드마크는 시스템 폰트가 아니라 한글 자소를 100단위 격자 위에 직접 세운 것이다.
`.wordmark` 의 텍스트를 `logo.svg` 로 교체한다.

### 표정은 지금 넣지 않는다

돋이는 눈동자 하나로 초록·주의·위험 표정이 나온다. 결과 화면마다 등장하니 공유
이미지가 되지만, 결과 화면·OG 이미지까지 작업이 늘어난다. **헤더·파비콘·랜딩만
먼저 하고 표정은 10/7 본선용으로 남긴다.**

## 6. 순서

```
1. mark/logo/favicon 적용 + 기존 체크 마크 제거      반나절
2. /scan 으로 index.html 이동, / 에 landing.html    반나절
3. 랜딩 절 ①~⑥ 작성                              1일
4. 데모 버튼 → /scan?demo= 자동 실행                반나절
5. (끝남) 235건 전수 측정 → 73.3% / 83.7% 두 숫자
   ⚠ 2026-09-12: 기준 추출기가 GPT 가 되어 **70.4% / 83.7%** 다 ([결정 1]).
6. ④ 절은 위 숫자로. 시피님 판정 뒤 한 숫자로 합친다
```

⚠ **1~2 를 먼저 배포해서 링크가 살아 있는지 확인한다.** 09-04 이후 배포 기록이
없어서 지금 배포본이 원격 main 과 같은지 모른다. 마지막 날 배포는 해커톤 실패의
전형이다(배포_Fly.io.md).
