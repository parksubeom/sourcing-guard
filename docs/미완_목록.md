# 미완 목록

결정이 필요하거나, 근거를 아직 못 본 것들. **제출 전에 코드를 건드리지
않기로 한 것은 그렇게 적어 둔다.**

---

## 1. 어린이 표지어가 상품명에 있을 때 CHILD_CATCH_ALL 을 열 것인가

**시피님 판단. 제출 전에는 건드리지 않는다.**

지금은 `CHILD_CATCH_ALL`(어린이제품 포괄 규정)이 두 조건을 함께 요구한다.

```
(1) age is CHILD_PRODUCT   페이지가 사용연령을 표기했고 만 13세 이하
(2) 등급 후보가 0건
```

'초등학생' 은 용도 설명이라 추출이 `target_age` 로 옮기지 않는다. 그래서
`EVERYGOOD 학생용 대용량 책가방 백팩 초등학생` 화면에는 품목도 포괄 규정도
없이 `info_request` 세 줄(재질·대상연령·품목 구분)만 남는다. 실물에서
확인했다 - `category=unclassified`, `target_age=None`.

### 이것이 설계 공백일 수 있는 이유

**같은 표지어를 두 곳에서 다르게 다룬다.**

| | 어린이 표지어를 | 근거 |
|---|---|---|
| `ALIASES_IF_CHILD_MARKED` | **신뢰한다** | 셀러가 페이지에 적은 사실이다 |
| `CHILD_CATCH_ALL` | 신뢰하지 않는다 | verifier 주석 "UNKNOWN 에는 안 붙인다" |

### 열면

초등학생 책가방·유아 모기장처럼 표지어가 명확한 줄이 포괄 규정으로 답을
받는다. "개별 안전기준이 없는 공급자적합성확인대상어린이제품은 어린이제품
공통안전기준을 적용한다" (시행규칙 별표 3 제2호)는 원문이 문장으로 적어 둔
확정된 답이라, 판별 못 함 대신 답을 줄 수 있다.

### 위험

'어린이날 선물'·'어린이 인기' 같은 **용도어**에 걸린다. 그러면 모든 상품에
붙는 소음이 되고, 셀러가 이 문장을 읽지 않게 된다 - 코드 주석이 걱정한
그대로다. R3 경계다.

### 판단 재료

- 열 쪽 근거: `ALIASES_IF_CHILD_MARKED` 가 같은 표지어를 이미 신뢰한다
- 닫을 쪽 근거: verifier 주석 "UNKNOWN 에는 안 붙인다"
- 중간안: 표지어 중 **연령을 직접 말하는 것**(`초등`·`유아`·`키즈`)만 열고
  용도어(`어린이날`)는 제외 - 다만 그 구분을 우리가 정하는 것이 판정에
  가까워진다

## 2. 어린이용 가방이 어느 품목인가 — 원문 미확인

「공급자적합성확인대상 어린이제품의 안전기준」 부속서를 아직 못 봤다.
표에 `아동용 섬유제품`(별표 3 '거' 항목)이 있지만 **그 범위에 가방이
포함되는지** 확인 전이다. 짐작으로 매핑하지 않는다 (R5).

확인되면 `ALIASES_IF_CHILD_MARKED` 에 `백팩`·`책가방` 을 어린이 품목으로
넣을 수 있고, 지금 회색으로 남는 189번(초등학생 책가방)이 답을 받는다.

## 3. 안전기준준수 부속서 1 의 제품류 전체 목록 — [AA]

지금 아는 것은 '기타 제품류' 열거뿐이다.

> "가방, 쿠션류, 방석류, 모기장, 커튼, 수의, 덮개 등" (만 14세 이상 가정용)

수건·타월이 어느 제품류인지 모른다. 그것을 알면 145번(곰돌이비치타월)을
그 품목으로 보내 경쟁 규칙에서 튜브를 양보시킬 수 있고, 그러면 [V]가
순수 +3 이 된다.

⚠ 이름이 같은 부속서가 둘이다. 헷갈리지 말 것.

| | 대상 | 우리 쪽 용도 |
|---|---|---|
| **안전확인** 부속서 1 | 유아용 섬유제품 (36개월 미만) | `KC-ANNEX1-*` draft 12건의 출처 |
| **안전기준준수** 부속서 1 | 가정용 섬유제품 (만 14세 이상) | 모기장·가방 별칭의 근거 |

## 4. 그 밖에 기록만 해 둔 것

- **지우개 접두 용도어 규칙** — 맞음 4 / 오답 4. 순 이득 0 이라 안 넣었다
- **'헬멧' 별칭의 용도 과다 특정** — 표에 `승차용`·`자전거용`·`롤러스포츠용`·
  `등산용`·`스키용`·`야구용` 6종이 있어 '헬멧' 하나로는 갈린다. 갈림이
  정확한 동작이므로 지금은 그대로 둔다
- **`coverage` 어휘 불일치** — `coverage.categories` 는 서술용으로만 남겼고
  게이트에 쓰지 않는다 (CLAUDE.md §5). 룰을 승격할 때 함께 갱신할 것
- **5번 줄 `product_name` 추출 실패** — LLM 이 빈 값을 냈다. 원본 게이트가
  덮어 주므로 등급은 붙지만, 추출 실패 자체는 남아 있다
- **일일 LLM 상한이 배포마다 초기화된다** — 카운터가 메모리에 있어
  `/healthz` 의 `daily_llm_used` 가 재시작하면 0 이 된다. 상한이 실제로
  강제되지 않는다
- **별표 6 에 마스크가 없다** — 우리 표의 별표 6 은 20건이고 마스크가
  없다. 부속서 17 이 2025-12-29 시행이라 우리 운용요령 사본보다 나중이다.
  그래서 `KC-SDOC17-*` 12건은 지금 표에서 걸릴 품목이 없다
