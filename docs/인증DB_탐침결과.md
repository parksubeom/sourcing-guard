# KC인증 DB 탐침 결과 (2026-09-06)

`cert/certificationList.json` 을 `conditionKey=productName` 으로 소량 탐침했다.
전량 조회(`conditionValue=%`)는 던지지 않았다 — 규모를 먼저 재는 것이 목적이었다.

## 결론 한 줄

**인증 DB 는 셀러 어휘 → 법령 품목명 사전을 정부가 이미 만들어 둔 것이다.**
다만 **인증·신고 대상만** 들어 있어 안전기준준수대상(별표 7)은 못 덮는다.

---

## (a) categoryName 이 표의 어휘와 같은가 — **같다. 마지막 마디만 떼면 된다**

계층형이고 마지막 마디가 561/35 표의 품목명과 **문자열까지 일치**한다.

| 검색어 | categoryName | 마지막 마디 | 표에 있나 |
|---|---|---|---|
| 에어프라이어 | `전기기기>주방용 전열기구>전기오븐기기` | 전기오븐기기 | ✅ |
| 전기주전자 | `전기기기>전기액체 가열기기>전기주전자` | 전기주전자 | ✅ |
| 가습기 | `전기기기>가습기>가습기` | 가습기 | ✅ |
| 필통 | `어린이>학용품` | 학용품 | ✅ |
| 모발건조기 | `전기기기>모발관리기>모발건조기` | 모발건조기 | ✅ |
| 매트 | `안전기준준수대상 생활용품 > 생활 > 침대 매트리스 > 침대 매트리스` | 침대 매트리스 | ✅ |

⚠ 표기가 흔들린다. 같은 뜻에 두 형태가 온다 — `어린이>학용품`(9,337) 과
`안전확인대상 어린이제품 > 어린이 > 학용품 > 학용품`(6,988), 그리고 오타
`학용퓸`(30). 마디 수도 2~4로 다르다.

## ⭐ 예상 못 한 수확 — productName 의 괄호가 곧 사전이다

**괄호 밖이 법령 품목명, 괄호 안이 통칭**이다.

```
전기오븐기기(에어프라이어)        → 에어프라이어  = 전기오븐기기
주방용전열기구유사기기(에어프라이어)
학용품 (필통)                   → 필통        = 학용품
학용품 (지우개)                 → 지우개      = 학용품
전기건조기(신발건조기)            → 신발건조기   = 전기건조기
전기건조기(우산건조기)            → 우산건조기   = 전기건조기
모발건조기(Hair Dryer)          → 영문 통칭도 있다
전기매트(Warmer Pad)
```

우리가 손으로 만들던 별칭을 **정부가 이미 등록해 뒀다.** LLM 없이 정부
데이터끼리 잇는 것이라 R1 과 무관하다.

## (b) certDiv 가 표의 등급과 맞는가 — **맞지만 구법 표기가 섞인다**

| certDiv | 뜻 |
|---|---|
| `전기용품 및 생활용품 안전관리법 대상>안전인증대상 전기용품` | 현행. 안전인증 |
| `전기용품 및 생활용품 안전관리법 대상>안전확인대상 전기용품` | 현행. 안전확인 |
| `어린이제품 특별법 대상>안전확인 대상` | 현행. 안전확인 |
| `전기용품안전관리법 대상>안전인증 대상` | **구법**(전안법 이전) |
| `전기용품안전관리법 대상>자율안전확인 대상` | **구법**. 지금의 안전확인 |
| `품질경영 및 공산품안전관리법 대상>자율안전확인 대상` | **구법**(공산품법) |

완구 145,032건 중 35,527건(24%)이 구법 표기다. 매핑표가 필요하다.

## (c) 규모 — **전량 조회는 던지면 안 된다**

`numOfRows` 는 **무시된다.** 10을 줘도 전량이 온다(가습기 4,482행으로 확인).

| 검색어 | 행 | 응답 | 시간 |
|---|---|---|---|
| 필통 | 19 | 0.01 MB | 0.6초 |
| 가습기 | 4,482 | 3.17 MB | 1.1초 |
| 매트 | 8,755 | — | — |
| 학용품 | 16,412 | — | — |
| **완구** | **145,032** | **약 103 MB 추정** (0.7 KB/행) | — |

검색어 하나가 14만 행이다. `conditionValue=%` 전량이 몇 자릿수일지 모른다.
**핸드오프 §4 의 경고가 그대로 유효하다.**

인증·신고 절차가 없는 품목(운용요령 별표 7, 51건)은 인증 DB 에 등록될 이유가

| 우산 | 5 | 우산이 아니라 `전기건조기(우산건조기)` |

새표본235 의 대상 136건 중 신발류·매트류·섬유제품·가방이 상당수라, 이 경로만
으로는 그쪽을 못 덮는다. 별표 7 쪽은 여전히 부속서 서문 수집이 필요하다.

## 검색 동작

부분 문자열 매칭이다 — `학용품 (지우개)` 가 '지우개' 로 걸린다. 다만 띄어쓰기·
표기가 정확해야 한다.

- `헤어드라이어` **0행** ↔ `드라이어` 23행 ↔ `모발건조기` 4,906행
  → 등록명이 '모발건조기' 라 셀러 어휘로는 못 찾는다. **괄호 사전이 필요한
    이유가 이것이다.**
- `크레파스` 0행 → 크레파스로 등록된 제품이 실제로 없다
- `블루투스스피커` 0행 ↔ `스피커` 2,963행(`앰프 내장형 스피커`)
