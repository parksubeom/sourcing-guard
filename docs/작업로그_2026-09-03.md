## 6. 이 세션에서 배운 것 (반복 방지)

**첨부 인코딩은 되돌릴 수 없이 깨질 수 있다.** UTF-8 을 Latin-1 로 읽으면 한글
바이트의 절반이 C1 제어문자가 되어 화면에서 사라진다. 눈에 보이는 모자이크만
받아 적어도 원문이 안 나온다. 패치를 다시 줄 때는 base64 나 zip 으로.

**`resultCode=00` + 빈 목록은 두 가지를 구별하지 않는다.** 관세청 API 에서
"요건이 없다" 와 "질의를 잘못했다" 가 같은 응답이었다. 접두 4자리도, 존재하지
않는 10자리도, 요건 없는 실존 코드도 전부 같은 모양이다. 첫 시도에 그걸 "우리
축에는 요건이 없다" 로 읽을 뻔했다 — 링크 유효성 실측(UA 차단)과 RRA 타임아웃
편향에 이어 **같은 종류의 실수를 세 번째로 잡았다.** 빈 결과를 결론으로 쓰기
전에 "이 도구가 답할 수 있는 질문이 맞는지" 를 먼저 확인할 것.
