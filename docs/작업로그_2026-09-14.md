### 1-2. 주소는 200 이 아니라 **본문**으로 확인했다

`law.go.kr` 은 한글주소를 못 찾아도 **200 을 준다.** 대조군까지 재서 확인했다:

```
GET /법령/어린이제품안전특별법시행규칙          200  <title>어린이제품안전특별법시행규칙</title>
GET /행정규칙/전기용품및생활용품안전관리운용요령  200  <title>전기용품및생활용품안전관리운용요령</title>
GET /법령/어린이제품안전특별법시행규칙/별표2      200  <title>국가법령정보센터 | 오류페이지</title>
GET /법령/어린이제품안전특별법시행규칙없는이름XYZ 200  <title>국가법령정보센터 | 오류페이지</title>
```

**별표 단위 주소는 없다.** `curl -sI`(HEAD)는 네 주소 전부 404 를 주므로 그것도
판단 근거가 못 된다. CLAUDE.md §6 의 "오류가 아니면 성공" 자리다 — 상태 코드로
확인했으면 없는 주소를 근거로 붙였다.

### 1-4. 인수 — **빈 화면을 재지 않게** 고쳤다

인수 스크립트가 도구 화면 셋을 열기만 하고 글꼴·파비콘만 봤다. 세 화면 다 기본
상태가 비어 있어서 **아무것도 재지 않고 통과**하고 있었다. 이제 /scan 은 실제로
검사를 돌리고, /batch 는 네 줄을 넣어 누르고, /watch 는 항목이 있는 응답으로 열고
나서 잰다 — 그려졌다는 증거 선택자를 못 찾으면 그 화면은 실패다.

### 1-5. 확신 못 하는 것

- `_performance_statement`(승차용 안전모·휴대용 레이저 두 룰)가 **죽은 코드**다.
  `if performance` 가지에서 문장을 만든 뒤 아래 `limit` 블록이 그것을 덮어쓴다.
  실측: "이 품목에는 '승차용 안전모 안전요건' 기준이 적용됩니다. 시험성적서로
  확인이 필요합니다." — 통과해야 할 시험 이름과 정부 조사 부적합률이 사라진다.
  **거짓은 아니고 덜 알려주는 쪽이다.** ① 이 여는 범위 밖이라 고치지 않았다.
- 카드 푸터와 페이지 푸터에 §9 문구가 **둘 다** 뜬다. 정본이 카드 푸터에 넣으라고
  했고 페이지 푸터는 결과가 없을 때도 §9 를 지켜야 해서 둘 다 뒀다.
