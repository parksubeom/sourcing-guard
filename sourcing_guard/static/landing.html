1. 무엇을 확인하나

KC 인증번호 조회
번호가 국가기술표준원 인증 DB 에 실재하는지, 상태가 무엇인지(적합·취소·효력상실 등)를 조회합니다.
리콜 대조
국내·국외 리콜 공표 목록과 모델명·인증번호·제조사로 대조합니다. 건수는 아래 5절에 매일 갱신됩니다.
유해물질 기준
고시·부속서 원문에서 우리가 직접 만든 규칙 DB 로, 이 품목에 어떤 기준이 걸리는지 보여 줍니다.

세 칸 모두 결과마다 정부 원문 링크가 붙습니다. 근거 없는 항목은 화면에 나올 수 없게 만들어져 있습니다.

2. 무엇을 하지 않나

합법인지 불법인지 판정하지 않습니다.

  • 초록불은 보증이 아닙니다. 우리는 상세페이지에 적힌 글을 읽고, 단속은 실물을 수거해 시험합니다.
  • 확인하지 못하는 것: 인증번호 도용, 실제 함유량, 아직 공표되지 않은 리콜, 식약처 소관 품목, 상표권·원산지.
  • 이것은 빠진 기능이 아니라 이 도구의 전제입니다. "걸리지 않는다" 고 말하는 순간 사후 책임이 도구 쪽으로 옵니다. 그래서 사실과 근거만 놓고 판단은 셀러가 합니다.

3. AI 는 어디에 쓰나

언어 모델이 하는 일
상세페이지에서 상품명·모델명·재질·연령·인증번호를 뽑고, 법령 품목명으로 옮겨 적습니다. 추출·분류·설명까지입니다.
언어 모델이 하지 않는 일
위험도 판정. 신호등은 결정론 코드가 정부 조회 결과와 규칙 DB 만으로 계산하고, 같은 입력에는 항상 같은 답을 냅니다.
코드로 강제한 것
근거 URL 없는 결과는 생성 자체가 실패합니다. 단정 문구는 생성자에서 거부됩니다. 규칙 DB 는 사람이 원문과 대조해 승격한 것만 점수에 들어갑니다.
